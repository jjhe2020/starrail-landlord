# 星穹转轮 · Starrail Landlord

0.7.0 可玩测试版 · 在浏览器中运行的星穹铁道主题转轮构筑游戏，适配桌面与手机。灵感来自《幸运房东》的符号构筑循环，使用独立实现的规则引擎与界面。

角色名单沿用已核对的维基 revision 472778 快照（全部非开拓者角色、公布形态与额外星神阿哈），名单与归属见 [角色证据](docs/CHARACTERS.md)。当前版本的设计说明与 90 卡技能表见 [0.7 角色设计](docs/CARD-ROLES-V070.md)，统计方法见 [预声明测试协议](docs/V070-TEST-PROTOCOL.md)。本轮已完成14,500场对局与345,600条逐卡受控场景；实际结论见[0.7测试报告](docs/V070-BALANCE.md)，旧版结果不能作为本版平衡证据。

## 可以玩什么

- **五列战斗**：5 列 × 4 行转轮，角色攻击对应列。单体 3 倍、扩散主目标 2 倍与邻列 1 倍、群体所有敌人 1 倍；空列寻找最近存活敌人。Boss 固定在中列。
- **自由难度**：直接选择 1–20 档，无需逐级解锁；难度档位与本局第几关独立，高难提高敌人生命。交租模式已移除。
- **构筑**：90 个角色条目、64 件奇物、32 种奇物精华、21 种正式羁绊和 10 组剧情委派；三选一招募、免费或信用点重掷、移除、成长、相邻强化、临时角色召唤与消耗。精华记录取得后的条件与进度，解锁后一次性奖励不重复领取，后续被动按规则生效。
- **职责与公开标签**：攻击、防御、即时增幅、永久培养和敌方干扰相互配合。技能根据命途、属性、正式阵营和职责筛选受益者；图鉴显示主职、阵营、适配对象和触发条件，可按公开标签检索。支援不进行普通攻击。
- **空间配合**：绝大多数技能以相邻八格为主，辅以同行、同列、边缘、角落、孤立和相邻空位。攻击者保留基本攻击，靠实际落位获得额外收益；培养、增幅、易伤及防御都有具体空间边界。内部“套路”只表示测试拿牌偏好，不是角色标签，也没有成型战斗奖励。
- **培养**：攻击培养提高威力，支援培养仅放大明确标记的职能效能，每点8%、最多计12点；培养主持不接受培养，成长不自乘；培养发放量升星按1/1.5/2温和提高。即时增幅同类上限×2.2，限定易伤总增量上限75%；培养需要输出、防御和干扰共同保护。
- **升星**：3 个同角色同星级自动合成。1 / 2 / 3 星威力倍率为 1 / 3 / 9。羁绊统计整个编队中的不同角色身份。
- **单局流程**：12 层、逐层奖励、敌方技能、护盾与治疗、胜负结算和无尽模式。
- **敌方条款**：32 种针对命途、攻击范围、成长、邻接、升星、角色技能与防御的负面效果。首领随阶段追加有效条款，换关清除；可查看[完整条款说明](docs/ENEMY-DEBUFFS.md)。
- **资源管理**：重掷、移除、信用点消费、生命与护盾管理四类；信用点可购买维修、护盾和下一轮超频，补给每关最多两次。
- **效果表达**：每条技能标注触发、目标、时效、叠加与星级规则；角色可查看上次威力的精确构成。「效果状态」区分本局成长、持有来源、待用超频与历史记录。21 种羁绊分别围绕邻接、周期爆发、击破追击、抵伤反击、治疗转盾、召援和经营，激活不等于每轮必定触发。
- **体验**：触屏竖屏布局、就地机制说明、图鉴、键盘空格转动、可关闭音效和动画、种子复现、本地自动存档。
- **AI 助手**：招募、奇物和精华的全部可选奖励与跳过都显示选择概率与理由；可以接管当前旅程，也可以另开独立对局做随机策略对照和参数训练。

这是包含完整单局流程的可玩原型，0.7已完成本轮测量，按可玩测试版交付，尚未证明全面平衡。内容池和具体效果是本项目的改编设计，尚未逐项复刻《幸运房东》的全部符号、道具、精华、成就和难度规则。脑暴与后续扩展保存在 [路线图](docs/ROADMAP.md)。

开启旅程时自由选择难度，再点击「启动转轮」，在每轮三选一中招募或跳过；完成每两关领取奇物、每三关领取奇物精华，第十二关直接结算胜利，之后可继续无尽。免费重掷用完后每次花费 8 信用点；在准备阶段可精简编队或购买补给。补给为 12 信用点恢复 18 生命、10 信用点获得 20 护盾、16 信用点令下一次转动威力提高 20%；超频不可重复堆叠。具体攻击与构筑说明可在游戏内「玩法手册」查看。

主要机制旁显示可见的「?」入口；点击问号、资源标签或数字、层数或生命进度条，都能查看就地小说明。「羁绊共鸣」标题和激活数量也可以点开查看统计规则。手机可直接点，也可长按 450 毫秒；桌面保留悬停 160 毫秒查看，点击后可固定阅读。键盘聚焦说明入口后，按 Enter 或空格打开说明，不会触发转轮。点击页面其他位置会收起说明，并直接执行那里的操作。图鉴、玩法手册、编队、设置和试验台使用无背景遮罩的小面板；必须结算的奖励和胜负仍保留对话框，背景不虚化。手机战场顶部的生命与护盾可以分别查看说明。招募、奇物和精华三选一期间，奖励面板顶部也有可点击的状态说明，查看不会替你选择奖励或消耗资源。

想看 AI 如何构筑，点击「AI 代打」：它会正常修改并保存**当前旅程**，可随时点击停止；查看说明或打开工具面板时暂缓行动，关闭后继续。AI 会评估重掷、移除、补给和资源保留。通常三张奖励加「暂不招募／跳过奖励」，实际全部奖励与跳过的概率合计 100%，是 AI 的选择倾向，并非通关概率；代打按未舍入的同一概率抽样，也会实际跳过。跳过的概率由当前构筑收益决定，避免为了拿奖励而稀释编队。奖励面板的「重新发现」和跳过按钮手机点击区域至少 48 像素高。

想评测规则，点击「自动测试」，选择局数、难度与资源对照。实验另开独立对局，不消耗当前旅程资源。界面上的选择概率是 AI 的动作倾向，不能当成胜率。当前 0.7 的正式测试同时观察逐卡职责收益、标签拿牌策略、位置与乘区，以及前中后阶段和不同敌阵；只报告总体胜率不足以说明卡牌平衡。独立种子、配对单位、实践差异门槛和补样规则见 [测试协议](docs/V070-TEST-PROTOCOL.md)。

本轮结果见[0.7测试报告](docs/V070-BALANCE.md)：D10基础AI61.0%，标签策略55.5%–74.0%，冰／列车等偏好已有显著优势；±10pp对基础AI比较6项等价、22项证据不足。D20仅0%–3%，属于压力地板。功能检查通过不代表所有卡与策略已平衡；终局90卡总表、成长分布和职能边际在离线报告中可直接查询。

0.6 已发布的角色绑定组和 2,200 场对局记录见 [0.6 历史证据](docs/V060-BALANCE.md)；0.5 成长诊断见 [历史逐卡诊断](docs/CARD-GROWTH.md)，0.5 套路实验见 [历史套路报告](docs/BALANCE-ARCHETYPES.md)，0.4 及更早资源实验见 [历史资源报告](docs/BALANCE.md)。这些版本的角色规则或策略不同，均不代表当前版本的成绩。

## 本地开发

需要 Node.js 22 或更新版本。游戏与开发工具均无外部运行依赖，无需账号或后端。

```sh
npm run dev
```

打开终端显示的地址（默认 `http://localhost:5173`）。端口已被占用时：

```sh
npm run dev -- --port 5174
```

手机与电脑连接同一个 Wi-Fi，启动局域网服务后，用手机访问电脑局域网 IP 对应的端口：

```sh
npm run dev -- --host --port 5174
```

0.7 调整公开标签与空间技能，建议先导出旧存档再新开局。有效旧存档保留进度和资源，后续按新角色能力结算，旧快照仅为历史；跨版本不保证同种子重演。存档仅保存在当前浏览器，不跨设备自动同步；单文件版提供存档导入、导出。开启新旅程会替换当前局；有效 v1 战斗存档迁移为难度 10，保留当前敌人与随机状态，下一关使用新规则。已有 v2 战斗存档保留原难度，旧污染说明更新为当前文案。旧交租存档明确提示模式已移除，不能导入为战斗进度。相同规则、算法、难度、资源范围、宇宙种子与操作才能精确复现旅程。

## 单文件发行版（默认）

### Android 与 PC 传文件直接玩

每次可交付版本在检查通过后提交并推送相关代码、文档与证据，创建对应 Git 标签和 GitHub Release，并上传当次带版本号的 HTML；仓库保持私有。本版成品和报告从[GitHub Release v0.7.0](https://github.com/jjhe2020/starrail-landlord/releases/tag/v0.7.0)下载。最终 HTML 可直接转发，首次打开无需联网、账号或后端。开发电脑先 `npm ci`，再运行 `npm run build:portable`；成品位于 `artifacts/`。PC 可直接用浏览器打开，Android 可传到下载目录，在文件管理器中选择「用浏览器打开」。游戏、全部图片、CSS 与 AI 都内嵌，不要用聊天软件或文档预览器的 HTML 预览代替浏览器。

本地文件的自动存档取决于浏览器与文件权限；设置提供「导出存档／导入存档」。关闭文件、移动文件、切换浏览器或传入新版前，建议导出存档。此方式已通过 Chromium 浏览器 `file://` 测试，尚未实测红米文件管理器的 `content://` 打开路径。iPad 文件 App 不保证执行交互式 HTML，应使用支持本地交互网页的浏览器或网页容器。

### 历史主屏幕安装版

原 ChatGPT Site 保留为历史安装入口，后续发布不再自动部署到该站点；正式版本以对应 GitHub Release 及其带版本号的 HTML 附件为准。主屏幕安装和缓存功能仍保留，供需要自行托管的人使用。

自行托管时，用手机 Chrome 或 iPad Safari 打开受信任的 HTTPS 安装网址，等待「离线已准备好」，再通过浏览器菜单／Safari 分享添加到主屏幕。保持联网从图标打开一次，确认准备完成后即可断网继续玩，电脑无需开机。

设置中的「离线与安装」显示准备状态、安装入口和更新。完整新版下载后，由玩家主动点击「保存进度并更新」才刷新当前页面。所有角色头像、图鉴和 AI 模块都随游戏缓存；失败的下载不会替换已有离线版。局域网 HTTP 地址仍可在线试玩，但手机无法从该地址保存离线游戏。

两台设备的存档独立；清除网站数据会删除存档与离线资源。完整安装步骤、浏览器与主屏幕存储差异和维护说明见 [离线指南](docs/OFFLINE.md)。

## 检查与静态构建

```sh
npm run check
npm test
npm run build
node scripts/server.mjs --dist --port 5174
```

`dist/` 是可直接部署的静态网站，所有资源使用相对路径，支持域名根目录和子目录。GitHub Actions 自动运行检查、测试并上传静态构建产物。当前仓库为私有，代码上传并不自动生成公开游戏网址。

命令行也能复现实验并保存 JSON 报告；`npm run balance` 默认使用 8 个复用 Worker、每批 50 局并行，按原种子顺序汇总，保持与串行策略相同结果，可用 `--workers 1`。`--runs` 是每策略的局数，战斗 AI 与均匀对照合计为其两倍：

```sh
npm run balance -- --difficulty 10 --runs 1000 --target-min 0.9 --target-max 0.98 --seed release-check
npm run train:ai -- --difficulty 10 --runs 100 --generations 2 --candidates 4 --holdout 200 --seed training-check
node scripts/resource-balance.mjs --runs 1000 --workers 8 --seed resources-release-check
```

普通对照报告保存到 `docs/benchmarks/balance-parallel-latest.json`，训练到 `training-latest.json`。可用 `--output` 指定位置、`--profile` 加载已保存策略；`--disable rerolls,removals,credits,defense` 指定资源对照。前三种开关限制真实动作，`defense` 只关闭防御规划与主动防御补给，保留自然治疗、护盾与正常承伤；是否有效使用由实际消耗/生成比判断。资源矩阵命令每组运行所选局数，默认 20 组；`--scope primary` 缩减为 9 组。`--require-target` 在资源验收未满足时保存报告并返回非零退出码。校准样本不能混入正式独立胜率。旧资源矩阵的口径见 [历史资源报告](docs/BALANCE.md)；当前卡牌与标签策略平衡以 [0.7 测试协议](docs/V070-TEST-PROTOCOL.md) 为准。

当前版本的三层实验使用 `scripts/balance-v070.mjs`，分别选择 `--mode cards`、`layers` 或 `campaigns`。`--samples` 在卡牌实验中是每卡的独立布局组数，在 campaign 中是每策略的完整对局数；共同种子下的多策略结果不能相加当作独立种子。校准与留出必须分区，正式复跑命令随 [本轮报告](docs/V070-BALANCE.md) 一起记录。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/content.js` | 90 个角色条目、64 件奇物、32 种精华及逐条效果定义 |
| `src/effect-rules.js` / `src/synergies.js` | 引擎与 AI 共享的效果条件、目标、数值及 21 种羁绊 |
| `src/effect-info.js` | 效果时效、历史快照与面向玩家的规则表达 |
| `src/engine.js` | 无 DOM 依赖的种子规则引擎 |
| `src/difficulty.js` | 规则版本、全关难度档倍率与第四关起的后期生命增幅 |
| `src/app.js` / `styles.css` | 浏览器交互与响应式界面 |
| `src/runtime.js` / `src/save-transfer.js` | 网页与单文件资源入口、可校验的存档导入导出 |
| `src/inspect.js` / `src/mechanics.js` | 就地说明控制器与机制文案 |
| `src/ai.js` / `src/ai-profile.js` / `src/ai-spatial.js` | 本地推荐、可校验参数与公开空间效益估算 |
| `src/archetypes.js` | 仅内部测试使用的公开标签拿牌偏好，无战斗奖励 |
| `src/balance-v070.js` / `scripts/balance-v070.mjs` | 逐卡、标签策略、位置与乘区的可复现实验 |
| `src/simulation.js` / `src/ai-worker.js` | 独立对局、参数训练与后台任务 |
| `src/balance-reference.js` | 已有版本的独立评测记录；版本不符时不作为当前结果 |
| `public/assets/` | 本地角色头像、原创敌人和背景 |
| `tests/` | 规则、AI、实验、静态服务器及可选真实浏览器回归 |
| `docs/` | 设计约定、引擎接口、素材来源与脑暴 |

具体规则见 [设计文档](docs/DESIGN.md)，接口和数值见 [引擎文档](docs/ENGINE.md)，浮层交互与 API 见 [交互文档](docs/INTERACTIONS.md)，验证方式见 [TESTING.md](TESTING.md)。角色头像归属 HoYoverse，来源与上游许可记录在 [ASSETS.md](docs/ASSETS.md)；敌人图形与界面由本项目制作。角色效果为改编设定。

版本变化见 [CHANGELOG.md](CHANGELOG.md)，后续工作见 [TODOS.md](TODOS.md)，项目协作约定见 [AGENTS.md](AGENTS.md)。
