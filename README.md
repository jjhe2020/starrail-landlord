# 星穹转轮 · Starrail Landlord

在浏览器中运行的星穹铁道主题转轮构筑游戏，适配桌面与手机。灵感来自《幸运房东》的符号构筑循环，使用独立实现的规则引擎与界面。

## 开发目标

1. 跑通转轮、符号选择、稀有度、奇物、精华、移除、重掷、递增房租、胜负与无尽模式。
2. 用星穹铁道角色替换符号，用奇物包装道具与精华。
3. 添加五列敌人、单体 / 扩散 / 群体攻击、敌方技能、角色羁绊与三合一升星。
4. 将后续脑暴整理成可修改的数据和规则，保留基础模式用于对比。

## 本地开发

需要 Node.js 22 或更新版本。游戏运行时无框架依赖，无需账号或后端。

```sh
npm install
npm run dev
```
