# 星穹转轮 · Starrail Landlord

在浏览器中运行的星穹铁道主题转轮构筑游戏，适配桌面与手机。灵感来自《幸运房东》的符号构筑循环，使用独立实现的规则引擎与界面。

## 可以玩什么

- **五列战斗**：5 列 × 4 行转轮，角色攻击对应列。单体 3 倍、扩散主目标 2 倍与邻列 1 倍、群体所有敌人 1 倍；空列寻找最近存活敌人。Boss 固定在中列。
- **房租挑战**：随机符号产出信用点，在期限前支付递增房租。
- **构筑**：24 名角色、20 件奇物、8 种余响、19 种羁绊；三选一招募、免费或信用点重掷、移除、成长、相邻强化、临时角色召唤与消耗。
- **升星**：3 个同角色同星级自动合成。1 / 2 / 3 星威力倍率为 1 / 3 / 9。羁绊统计整个编队中的不同角色身份。
- **单局流程**：12 层、逐层奖励、敌方技能、护盾与治疗、胜负结算和无尽模式。
- **体验**：触屏竖屏布局、图鉴与详情、键盘空格转动、可关闭音效和动画、种子复现、本地自动存档。

这是包含完整单局流程的首版可玩原型。内容池和具体效果是本项目的改编设计，尚未逐项复刻《幸运房东》的全部符号、道具、精华、成就和难度规则。脑暴与后续扩展保存在 [路线图](docs/ROADMAP.md)。

## 本地开发

需要 Node.js 22 或更新版本。游戏与开发工具均无外部运行依赖，无需账号或后端。

```sh
npm run dev
```

打开终端显示的地址（默认 `http://localhost:5173`）。端口已被占用时：

```sh
npm run dev -- --port 5174
```

手机与电脑连接同一个 Wi-Fi，启动局域网服务后，用手机访问电脑局域网 IP 对应的端口：

```sh
npm run dev -- --host --port 5174
```

存档仅保存在当前浏览器，不跨设备同步。切换模式和开启新旅程会替换当前局；损坏或版本不兼容的存档会重新开局。相同宇宙种子、相同操作与选择可以复现旅程。

## 检查与静态构建

```sh
npm run check
npm test
npm run build
node scripts/server.mjs --dist --port 5174
```

`dist/` 是可直接部署的静态网站，所有资源使用相对路径，支持域名根目录和子目录。GitHub Actions 自动运行检查、测试并上传静态构建产物。当前仓库为私有，代码上传并不自动生成公开游戏网址。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/content.js` | 角色、奇物、余响、羁绊数据 |
| `src/engine.js` | 无 DOM 依赖的种子规则引擎 |
| `src/app.js` / `styles.css` | 浏览器交互与响应式界面 |
| `public/assets/` | 本地角色头像、原创敌人和背景 |
| `tests/` | 规则与静态服务器回归测试 |
| `docs/` | 设计约定、引擎接口、素材来源与脑暴 |

具体规则见 [设计文档](docs/DESIGN.md)，接口和数值见 [引擎文档](docs/ENGINE.md)，验证方式见 [TESTING.md](TESTING.md)。角色头像归属 HoYoverse，来源与上游许可记录在 [ASSETS.md](docs/ASSETS.md)；敌人图形与界面由本项目制作。角色效果为改编设定。
