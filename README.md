# 星穹转轮 · Starrail Landlord

在浏览器中运行的星穹铁道主题转轮构筑游戏，适配桌面与手机。灵感来自《幸运房东》的符号构筑循环，使用独立实现的规则引擎与界面。

## 可以玩什么

- **五列战斗**：5 列 × 4 行转轮，角色攻击对应列。单体 3 倍、扩散主目标 2 倍与邻列 1 倍、群体所有敌人 1 倍；空列寻找最近存活敌人。Boss 固定在中列。
- **房租挑战**：随机符号产出信用点，在期限前支付递增房租。
- **构筑**：24 名角色、20 件奇物、8 种奇物精华、19 种羁绊；三选一招募、免费或信用点重掷、移除、成长、相邻强化、临时角色召唤与消耗。精华使用内部余响机制记录条件与进度，达成后永久触发一次。
- **升星**：3 个同角色同星级自动合成。1 / 2 / 3 星威力倍率为 1 / 3 / 9。羁绊统计整个编队中的不同角色身份。
- **单局流程**：12 层、逐层奖励、敌方技能、护盾与治疗、胜负结算和无尽模式。
- **难度曲线**：前三层保留原压力，第四至十二层平滑增压；末层敌人生命为原来的 1.50 倍、房租为 1.28 倍。以当前 AI 通关约 95% 为校准目标，允许 90%–98%。
- **体验**：触屏竖屏布局、就地机制说明、图鉴、键盘空格转动、可关闭音效和动画、种子复现、本地自动存档。
- **AI 助手**：招募、奇物和精华三选一显示选择概率与理由；可以接管当前旅程，也可以另开独立对局做随机策略对照和参数训练。

这是包含完整单局流程的首版可玩原型。内容池和具体效果是本项目的改编设计，尚未逐项复刻《幸运房东》的全部符号、道具、精华、成就和难度规则。脑暴与后续扩展保存在 [路线图](docs/ROADMAP.md)。

启动后点击「启动转轮」，在每轮三选一中招募或跳过；完成每两层领取奇物、每三层领取奇物精华，第十二层直接结算胜利，之后可继续无尽。免费重掷用完后每次花费 8 信用点；需要精简队伍时，在准备转动阶段打开「我的编队」移除角色。具体攻击与构筑说明可在游戏内「玩法手册」查看。

主要机制旁显示可见的「?」入口；点击问号、资源标签或数字、层数或生命进度条，都能查看就地小说明。「羁绊共鸣」标题和激活数量也可以点开查看统计规则。手机可直接点，也可长按 450 毫秒；桌面保留悬停 160 毫秒查看，点击后可固定阅读。键盘聚焦说明入口后，按 Enter 或空格打开说明，不会触发转轮。点击页面其他位置会收起说明，并直接执行那里的操作。图鉴、玩法手册、编队、设置和试验台使用无背景遮罩的小面板；必须结算的奖励和胜负仍保留对话框，背景不虚化。手机战场顶部的生命与护盾可以分别查看说明。招募、奇物和精华三选一期间，奖励面板顶部也有可点击的状态说明，查看不会替你选择奖励或消耗资源。

想看 AI 如何构筑，点击「AI 代打」：它会正常修改并保存**当前旅程**，可随时点击停止；查看说明或打开工具面板时暂缓行动，关闭后继续。三选一的百分比是 AI 的选择倾向，并非通关概率，代打按未舍入的同一概率抽样。

想评测规则，点击「自动测试」，选择模式和每策略 30 / 100 / 300 / 1,000 局，再运行平衡测试或训练。实验另开独立对局，不消耗当前旅程资源。训练每候选每模式最多 60 局，独立留出集每模型每模式最多 100 局；只有验收提高时才保存新策略。关闭面板后实验继续，可重新打开查看进度或点击「取消本次实验」。试验台初始显示 0.2.1 的 4,000 局独立发布评测：战斗 AI 96.7%、经典 AI 94.6% 通关。这是当前 AI 基准，不保证玩家或后续训练模型有同样胜率；完整方法与限制见 [AI 说明](docs/AI.md) 和 [平衡报告](docs/BALANCE.md)。

## 本地开发

需要 Node.js 22 或更新版本。游戏与开发工具均无外部运行依赖，无需账号或后端。

```sh
npm run dev
```

打开终端显示的地址（默认 `http://localhost:5173`）。端口已被占用时：

```sh
npm run dev -- --port 5174
```

手机与电脑连接同一个 Wi-Fi，启动局域网服务后，用手机访问电脑局域网 IP 对应的端口：

```sh
npm run dev -- --host --port 5174
```

存档仅保存在当前浏览器，不跨设备同步。切换模式和开启新旅程会替换当前局；损坏或版本不兼容的存档会重新开局。0.2.1 保留有效旧存档中的当前敌人和房租，下一层起使用新难度；无尽模式保留末层全倍率，再按原指数增长。相同规则版本、相同宇宙种子、相同操作与选择可以复现旅程，跨规则版本不保证相同结果。

## 检查与静态构建

```sh
npm run check
npm test
npm run build
node scripts/server.mjs --dist --port 5174
```

`dist/` 是可直接部署的静态网站，所有资源使用相对路径，支持域名根目录和子目录。GitHub Actions 自动运行检查、测试并上传静态构建产物。当前仓库为私有，代码上传并不自动生成公开游戏网址。

命令行也能复现实验并保存 JSON 报告；`--runs` 是每模式、每策略的局数，双模式对照总局数为其四倍：

```sh
npm run balance -- --mode both --runs 1000 --target-min 0.9 --target-max 0.98 --seed release-check
npm run train:ai -- --mode both --runs 100 --generations 2 --candidates 4 --holdout 200 --seed training-check
```

报告默认保存到 `docs/benchmarks/balance-latest.json` 与 `training-latest.json`。可用 `--output` 指定位置、`--profile` 加载已保存的策略或训练报告；`--target-min` / `--target-max` 检查每模式 AI 胜率，未达范围或有未完成对局时仍保存报告并返回非零退出码。0.2.1 的校准记录为 [calibration-v2.json](docs/benchmarks/calibration-v2.json)，独立发布记录为 [balance-v2.json](docs/benchmarks/balance-v2.json)；两者的样本不能混算。完整口径见 [平衡报告](docs/BALANCE.md)。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `src/content.js` | 角色、奇物、奇物精华、羁绊数据 |
| `src/engine.js` | 无 DOM 依赖的种子规则引擎 |
| `src/difficulty.js` | 规则版本与从第四层开始的难度倍率 |
| `src/app.js` / `styles.css` | 浏览器交互与响应式界面 |
| `src/inspect.js` / `src/mechanics.js` | 就地说明控制器与机制文案 |
| `src/ai.js` / `src/ai-profile.js` | 本地推荐策略与可校验参数 |
| `src/simulation.js` / `src/ai-worker.js` | 独立对局、参数训练与后台任务 |
| `src/balance-reference.js` | 游戏内展示的已有独立评测记录 |
| `public/assets/` | 本地角色头像、原创敌人和背景 |
| `tests/` | 规则、AI、实验、静态服务器及可选真实浏览器回归 |
| `docs/` | 设计约定、引擎接口、素材来源与脑暴 |

具体规则见 [设计文档](docs/DESIGN.md)，接口和数值见 [引擎文档](docs/ENGINE.md)，浮层交互与 API 见 [交互文档](docs/INTERACTIONS.md)，验证方式见 [TESTING.md](TESTING.md)。角色头像归属 HoYoverse，来源与上游许可记录在 [ASSETS.md](docs/ASSETS.md)；敌人图形与界面由本项目制作。角色效果为改编设定。

版本变化见 [CHANGELOG.md](CHANGELOG.md)，后续工作见 [TODOS.md](TODOS.md)，项目协作约定见 [AGENTS.md](AGENTS.md)。
