# 星穹转轮 v0.8.0 · 角色技能与属性版

已将 90 名角色的技能评审应用到 v0.7.1 美术版，并完成本轮规则重构和初次数值调优。

- 攻击力、默认攻击方式、默认倍率独立显示在卡面，逐角色配置具体数值；升星与永久强化修改相应属性。
- 统一使用“角色”和“追加攻击”；攻击力提高、造成伤害提高、敌方受到伤害提高分区计算，治疗和护盾使用各自倍率。
- 阿格莱雅创建衣匠，衣匠正常参与强化、羁绊和合成，完成第 2 次出场的全部结算后删除自身。
- 砂金·戏浪基础攻击力调整为 2.5、单体默认倍率调整为 300%；玲可治疗倍率调整为 150%、低血护盾倍率调整为 100%。数值配对测试与独立留出结果分开保留。
- 同步 AI、技能时序和战斗动效，修复实际攻击力减益、反击触发、创建角色合成与旧存档精华进度迁移。

附带的 `星穹转轮-v0.8.0.html` 是单个离线文件，图片、样式和 AI 已内嵌，首次运行无需联网或登录。请用浏览器打开。

**更新文件前请先从旧版导出存档。** 不同文件路径、版本和浏览器可能使用不同本地存储；新版支持有效旧战斗存档迁移及手动导入、导出。

验证：`npm run check`、完整单测、静态构建与离线构建通过；单测 689 通过，另行执行的离线浏览器检查 6/6、界面 169 项检查、动效 12/12 通过。移动屏宽与触控视口检查不代表 Android/iOS 实机兼容验证。

最终逐卡留出包含 90 名角色各 128 个布局组，共 345,600 条观察；另保留 17,920 条六轮后续轨迹和 9,600 条职能干预观察。重复场景数不等于独立样本数。
