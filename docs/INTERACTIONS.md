# 就地机制说明

角色、羁绊、奇物、精华与界面资源使用同一个小浮层说明。说明靠近触发控件，限制在可见屏幕内；不添加遮罩、背景虚化或焦点锁定，也不要求先点「了解了」才能继续操作。

0.2.2 为主要机制增加可见「?」入口，让现有说明更容易发现。问号、资源标签和数字、层数与生命进度条均可点击；羁绊标题与激活数量也能打开统计规则说明。层数、回合、信用点、生命、护盾、重掷和移除各自解释对应用途，手机战场的生命与护盾仍是独立入口。招募、奇物和精华三选一期间，奖励面板顶部也提供独立的状态说明，查看不会替你选择奖励或消耗资源，背景仍保持不可操作。

0.2.3 在三张奖励下显示跳过的 AI 推荐率与理由。点击、悬停或长按推荐说明只查看信息，实际跳过仍使用独立按钮。「重新发现」和跳过按钮桌面至少 46 像素高、手机至少 48 像素高；手机并列这两个操作，AI 代打独占下一行，避免过小的触摸目标。四项推荐合计 100%，代打与批量实验按同一原始分布执行领取或跳过。

- 桌面：直接点击问号或说明控件可固定阅读；鼠标悬停 160 毫秒后也会显示。鼠标可移进说明继续阅读；未固定时移出会自动收起。
- 手机：直接点击问号、标签、数字或进度条可打开说明，也可长按 450 毫秒后显示并保持。长按过程中移动超过 10 像素会取消，正常滚动不被阻止；已显示时继续滑动会收起。
- 点击说明外的任何位置会收起，同时照常执行该位置的交互；点击另一个详情控件直接切换。点击说明内部可以继续操作。滚动页面、调整窗口或按 Escape 也会收起。
- 键盘聚焦带有说明的控件时显示，按 Enter 或空格可固定打开；非原生说明控件会拦截这次按键，避免触发转轮。说明由 `aria-describedby` 与该控件关联。固定详情使用非模态 `dialog`；纯悬停说明使用 `tooltip`。
- 长按只拦截本次手势在同一个控件上产生的点击，避免误选奖励。下次按下立即清除拦截，不影响点击别的控件。

## 实现约定

`src/inspect.js` 导出 `createInspector({ root, resolve, onOpen?, onClose? })`，返回 `open(anchor, content?, { pinned? })`、`close()`、`isOpen()` 与 `destroy()`。

`resolve(anchor)` 返回 `{ title, bodyHtml, kind? }`，未知说明返回 `null`。调用方负责转义所有进入 `bodyHtml` 的非固定文本。`open` 默认固定；内部悬停调用使用 `{ pinned: false }`。

控件使用 `data-inspect="说明键"`，可以用 `data-id`、`data-index` 等字段传递内容标识。可点击入口设置 `data-inspect-click="true"`，资源标签、数字和进度条也使用该属性；可见问号使用有明确可访问名称的按钮。非原生点击说明控件的 Enter / Space 由控制器打开并阻止按键继续传播，原生按钮沿用浏览器点击行为，避免重复触发。不要让同一次点击再走旧的大弹窗详情处理。

浮层挂载在 `document.body`，结构为 `.inspect-popover > .inspect-heading (.inspect-title, 可选 .inspect-close) + .inspect-body`。CSS 负责视觉样式与内容溢出；控制器负责屏幕内定位。可用 `[data-inspector][data-state="open"]` 检测已打开浮层。

重新渲染应用前调用 `close()`，避免说明仍指向被替换的控件。局部刷新移除当前控件时，控制器也会自动收起说明；其他区域的更新不会打断阅读。销毁页面控制器时调用 `destroy()`，清除计时器、DOM 观察与事件监听。

## 浏览器回归

`tests/inspect.test.js` 使用真实浏览器 DOM 验证悬停、浮层内部阅读、详情切换、外部点击透传、长按防误选、滑动取消、手机屏幕边界与键盘说明。0.2.2 的同一入口新增非原生控件 Enter / Space 打开且不触发背景转轮的回归，7 项真实组件检查通过。它复用已安装的 Playwright 和浏览器，不添加项目依赖。设置 `INSPECT_BROWSER_TESTS=1` 后运行 `node --test tests/inspect.test.js`；Windows 使用系统 Edge，其他平台使用 Playwright 的 Chromium。常规 `npm test` 保持无需浏览器的引擎检查。
