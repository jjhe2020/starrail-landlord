# 0.6 角色职责与绑定组

本版本按已确认方向，把攻击、防御、即时辅助、永久培养和敌方干扰作为互相配合的五种职能。每个角色有一个主职能、1–3 个明确的绑定组。组名表示本作机械适配关系，不等同于官方阵营；所有技能均为本作改编，角色名称和头像归属保持原来源记录。

## 构筑原则

- **44 名攻击者**拥有实际常规攻击和专属追击程序。基础威力按普通、稀有、史诗、传说分别为 2 / 2.5 / 3 / 3.8；单体、扩散、群体及周期追击形成差异。
- **15 名防御者**只提供治疗、护盾和有条件的减伤。至少另一名同组伙伴同场或相邻才启动；按人数增加的技能最多计 2–3 人。
- **9 名即时辅助**主要给相邻、最强或满足条件的同场同组攻击者提供 1.3–1.6 倍增幅；少量副功能提高同组防御者的护盾效率。
- **10 名永久培养者**每 2–3 次登场培养最强 1 人或相邻最多 2 人，每人一星基础 +0.3–0.45；二星、三星培养量温和提高至 ×1.5 / ×2。仅培养同组的其他永久非培养角色；临时召援、见习委派和培养者不受培养。
- **12 名干扰者**给指定组或指定攻击形态提供 15%–35% 易伤，部分需同组伙伴配合才能降低敌方反击。易伤按实际攻击来源判断，不是全队通用增幅。

永久成长对攻击者增加基础威力；对非攻击者按 `1 + min(成长, 12) × 0.08` 增强其实际支援职责。倍率类技能只放大超出 1 的增幅部分，减伤倍率只放大减伤部分，培养技能本身绝不被成长放大。仅丹恒、三月七·巡猎、刃保留每 4 次登场 +0.15 的有条件自成长。

各组都有五种职能，但无需把名单全部集齐。重叠角色是跨组桥梁：例如阮·梅可在猎手、实验和击破之间连接培养，跨组之外的卡仍不自动得到她的培养。现有 8 套路保留身份门槛和核心要求，成型倍率降到 1.15–1.25，并取消套路自动永久成长；额外追击、抵伤反击和临时援军增幅均有具体触发。

## 委派与旧资源的适配

10 组剧情委派及其来源保留。主持每 3 次登场的永久成长由 1.5 降至 0.35，成长按一星/二星/三星 ×1/1.5/2；金币由 4 改为 2；只有攻击主持获得本次 +1.5 威力。寒鸦属于培养者，培养不吃自身成长，因此该委派不再给她无效成长，改为 3 信用点。见习补充、保护最后一位正式角色、高星、核心及已培养实例的规则继续生效。

21 羁绊保留 ID，攻击威力和追击都限制为攻击者。存护羁绊的抵伤反击由队伍中的攻击者兑现；防御者本身不因累积威力而攻击。换境桂冠精华改为提升存护防御者护盾获取量，避免旧威力奖励对其失效。
