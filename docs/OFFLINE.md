# 单文件发行与离线游玩

## 默认发行：传文件的单页版

最终版默认以单个 HTML 交付，不再随每次发行自动更新 ChatGPT Site。现有站点先保留；只有用户另行要求，才部署或调整站点。

游戏本身没有后端运行要求。`npm ci` 后执行 `npm run build:portable`，按 `package.json` 版本号生成 `artifacts/星穹转轮-v0.4.0.html`；之后的版本使用对应版本号。只需分享这个 HTML，无需同时传文件夹、服务器或账号。该文件包含普通脚本形式的游戏与 AI、全部图片和样式，以及素材来源与许可记录；不使用 Service Worker，不加载外部模块，首次运行也无需网络或登录。

PC：将 HTML 保存在电脑上，用 Chrome、Edge 等浏览器打开。文件可复制到其他电脑，浏览器直接运行内嵌游戏。

安卓：将 HTML 传到下载目录，使用文件管理器的「打开方式／用其他应用打开」选择 Chrome 等浏览器。聊天软件或文件预览器可能只展示源码或静态预览，不能代表游戏无法离线运行。系统需要允许浏览器读取被分享的文件；红米实机的具体打开入口尚未验证。

设置显示当前浏览器是否能自动保存，提供 JSON 存档导出与导入。读取存档后仍经过现有引擎校验，拒绝损坏、超大与不兼容文件；导入替换当前旅程，并恢复设置、统计和 AI 参数。无法自动保存时仍可在当前页面玩，关闭前须导出存档。文件路径、浏览器或新版 HTML 可能使用独立存储，更新前请备份。

单文件版更新通过传入新版文件。建议先导出 JSON 存档，在新版中导入，确认进度后再整理旧文件。桌面 Chromium 的真实 `file://` 离线测试覆盖桌面、320px 和 390px 等宽度，但没有替代 Android 文件分享入口的实机验证。iPad Files／QuickLook 不保证执行完整交互网页；其他移动系统也需用能执行本地 HTML 脚本的浏览器打开。

## 现有站点与主屏幕离线版（可选）

已部署站点仍支持添加到主屏幕，但不是后续最终版的默认交付入口，内容可能落后于最新 HTML。首次联网保存完整游戏后，可断网重新打开、继续当前旅程，角色头像、图鉴、音效与 AI 也在设备上运行。

## 第一次安装

安装网址：[星穹转轮离线版](https://astral-reels-offline.aglowskink6.chatgpt.site)。

1. 用红米上的新版 Chrome，或 iPad 上的 Safari 打开安装网址。私人安装网址首次访问需登录站点所有者的 ChatGPT 账号。
2. 等转轮下方显示「离线已准备好」。点击这个提示或右上角设置，可查看准备状态。
3. 红米：浏览器菜单 → 添加到主屏幕；浏览器支持直接安装时，设置中也会出现安装按钮。iPad：Safari 分享 → 添加到主屏幕。
4. 保持联网，从新建的主屏幕图标打开一次，再次确认「离线已准备好」。这可以确认主屏幕应用自己的存储已准备完成。
5. 开启飞行模式，退出后重新打开主屏幕图标，确认游戏与已有进度正常加载。之后电脑无需保持开机。

主屏幕安装地址必须使用受信任的 HTTPS。电脑开发时的 `localhost` 可以验证离线功能，但手机打开 `http://192.168.*` 局域网地址只能在线试玩，无法准备主屏幕离线缓存。下载的单文件 HTML 按上文直接运行，不需要走主屏幕安装流程。

## 进度、存储与更新

- 存档属于当前设备、浏览器与网址；手机和 iPad 不自动同步。浏览器窗口与主屏幕应用的存储在部分系统上也可能独立，请在以后常用的入口开始旅程。
- 清除网站数据、卸载时清除数据、使用无痕浏览，或系统回收网站存储，都可能删除离线资源或存档。离线缓存不是存档备份；空间不足时需要重新联网准备。
- 新版本在联网时下载完整资源。已打开的对局不会自动刷新；设置出现「保存进度并更新」后，主动点击才会保存并重新打开。若浏览器不允许保存，更新不会关闭当前页面。
- 下载缺少任何资源、遇到登录页面或网络错误时，新版不会替换已有完整离线版。联网后在设置中检查更新或重新准备；私人网址会话过期时，先恢复登录。
- 关闭所有使用旧版的窗口后，新版本也可在下次打开时生效。更新期间不同窗口的资源按各自版本保留，避免运行中混用脚本。

## 实现与维护

`scripts/build-portable.mjs` 从版本号生成成品文件名，并把版本号嵌入标题和配置。CI 上传 `artifacts/星穹转轮-v*.html`；每次构建的分享成品就是一个 HTML。可向脚本传入自定义 `.html` 输出路径，但正常发行保持带版本号命名，便于识别新旧文件。

`manifest.webmanifest` 声明相对安装路径、主屏幕显示方式及原创 PNG 图标。`src/offline.js` 负责注册、状态、安装提示和用户主动更新；不修改规则引擎。

`scripts/offline-assets.mjs` 收集实际运行资源并按文件内容计算缓存版本。开发服务器与静态构建使用同一生成器，将完整资源清单嵌入 `service-worker.js`。清单包括 HTML、CSS、所有浏览器模块与 AI Worker、角色和敌人素材、安装图标、归属记录；不包括项目文档、测试、Git 或账户页面。

构建后的 `dist/` 可部署到域名根目录或子目录。全部预缓存完成后才激活新版本；缓存以安装范围区分，清理只处理本项目的缓存。浏览器缓存可被系统清除，准备状态需检查完整缓存后才能显示。

原始首页内容同时嵌入生成后的 Worker，保存离线首页时生成原始 HTML 并校验其摘要，避免托管平台首页跳转或附加验证脚本影响离线准备。其他资源仍通过网络下载并逐项校验。

验证方式见 [TESTING.md](../TESTING.md)。
