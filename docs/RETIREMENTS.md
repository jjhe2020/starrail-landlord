# 角色委派与永久退场

规则更新日期：2026-10-21（0.7 候选）。本作把《幸运房东》中“配对消除符号并获得收益”的机制改编为角色完成委派、交接、训练或休假后永久离队；不表示角色死亡。以下人物关系有原作依据，委派名称、见习副本、触发频率和收益均为本作设计，不是官方剧情或技能。

## 结算规则

规则数据在 `src/retirements.js`；引擎在每次随机摆盘后、角色登场技能和攻击前结算。同场八邻接、不跨行绕边，每位正式主持者累计每三次实际登场最多委派一人。未抽中、未到频率或没有合格相邻者时不生效；不会预扣角色或发放空收益。

正式受体须是一星，永久成长不超过 1，且同名正式角色至少还留一位。二星、三星及成长超过 1 的正式培养实例受保护。内部拿牌策略不产生核心身份或额外保护。临时召援不能充当正式委派对象。候选中优先选择系统见习委派，再选择成长和登场次数较低的额外正式副本。

实际结案后，受体当轮不发动登场技能、不攻击，并从 `roster` 永久删除。普通主持者获得永久成长 **+0.35** 与 **2 信用点**；成长按主持者 1 / 2 / 3 星乘 **1 / 1.5 / 2**，再受鲁珀特齿轮、成长审查及永久成长倍率影响。寒鸦是培养主持者，结案不增加自身成长，改获 **3 信用点**，避免培养递归。

只有攻击职责的主持者（姬子、希儿、克拉拉、托帕&账账）另获本次攻击威力 **+1.5 × 星级倍率**，这里攻击星级倍率为 **1 / 3 / 9**。其他主持者没有本次攻击加成；它们获得的永久成长按自身职责增强明确标记的支援效能。结案记入本轮 `retirements`，可供有空间条件的退场技能、奇物与余响读取，不授予内部套路奖励。

已拥有过关系中的正式受体或曾完成该组委派后，主持者每四次实际登场可补充一位系统见习委派。新副本从下轮开始抽取，同规则在整个编队与本轮待加入队列中合计最多待办一位；多名主持者不能同时刷出多个待办。见习副本是一星、持有 `commission` 与 `origin` 标记，不计正式羁绊身份、不参与自动合成，也不能主持另一组委派。它能正常登场，但无自然到期时间；以此保证供给不会因三次随机摆盘未相邻就自动耗尽。见习可结案而不受“最后正式一位”或正式实例成长保护限制，因为它由系统专门提供，玩家投入培养的正式实例仍受上述规则保护。

玩家只拿主持者时不会凭空启动循环。最后一名正式受体不会自动消失，若要把该身份彻底移除仍可使用普通移除资源。这个设计保留最后正式身份，也让“招募多余低星 → 结案瘦身”和“已建立关系 → 循环结案成长”同时存在。

## 状态、解释与兼容

- `getRetirementPreview(state)` 返回当前主持者的配对、下次触发登场、可委派实例与完整规则；`retirementRulesFor(id)` 为角色详情提供关系、说明与来源。
- `lastSpin.effects` 使用 `retirement`（实际结案）、`commission`（补充待办）、`growth`、`power` 和 `coins` 记录，可查询真实实例 UID；日志明确显示永久离队与收益。
- `state.retirementStats` 记录 `completed / permanent / supplied` 及 `byRule` 同结构计数；`permanent` 只计原招募副本，`completed` 还包括系统见习。
- `stats.destroyed` 保留历史通用退场计数含义；累计委派统计单独保存，避免把所有退场都误当正式瘦身。
- 兼容旧 v2 存档，缺失委派统计时补零。导入校验委派规则、受体身份、一星、非临时、来源 UID 格式、结案标记和统计加总；不会读取存档里的效果配置来执行规则。

## 验证与参数探针

AI 通过 `src/retirement-ai.js` 估算有限后续回合内的真实结案次数，并把收益接入 `estimateEffectsForAi` 的永久成长率、当轮威力与经济字段。模型使用公开编队、登场计数、二项抽取分布和随机八邻接概率，追踪有限普通素材库存及同规则最多一位待办，不读取种子、随机状态或上轮摆盘。最后一位正式受体只解锁后续供给，不反复当作可吞素材。高星受体、临时主持者、系统见习主持者和已超成长阈值的正式素材均不产生虚假收益；成长预测会关闭即将超阈值的普通素材窗口。

预计结案发生得越晚，平均永久成长收益越低。AI 同时扣除素材离队后的预计上场输出、三月七护盾和原有邻接辅助贡献；信用点消费关闭时经济估值归零，永久成长仍保留。最后一关以真实剩余回合封顶，没有机会先补给再结案时不给循环收益。委派率也传给读取退场事件的角色、奇物与余响估值。此为有限公开信息近似，多个主持者之间的抽取相关性、所有未来随机增益与供给导致的后续人口变化未作完整状态穷举，真实引擎反事实摆盘仍用于最终动作评估。

时点评审：正式委派至少保留一名普通同身份角色，因此不改变本轮永久身份集合；系统见习从正式羁绊身份排除。内部策略不参与结算；正式身份统计不会把系统副本当作新身份。相邻登场目标、临时效果来源和攻击通过 `consumed` 集合排除已委派者。存档再核对同规则待办最多一位、待办不超过未结供给余额以及累计结案不超过通用退场计数。

`tests/retirements.test.js` 覆盖十组真实引擎结算、同场邻接和频率、保留末位、星级与成长保护、移除前技能屏蔽、循环供给、跨主持者待办上限、不参与合成、正式羁绊身份排除、确定性、存档兼容与伪造标记拒绝。

以下保留早期委派模型的隔离探针记录，不作为 0.7 的强度或平衡验收。循环机制探针使用 200 个种子、姬子与最后一位正式三月七，保持敌方靶不死亡、无反击，连续执行 32 次真实转动并跳过招募。平均完成 **2.305 次**、生成 **3.305 位**见习，完成数为 **0–5 次**。这是对供给和邻接的隔离测试，不代表通关胜率。无关系受体时供给为零；有关系后待办受上限约束，不能无限堆满编队。随机邻接仍存在等待成本，当前卡牌、标签策略、位置与乘区的结论需以 [0.7 测试报告](V070-BALANCE.md) 为准。

相同公开初始条件下，有限模型预测 32 轮完成 **2.3186 次**。`tests/retirement-ai.test.js` 用另外的实际引擎动作累计 100 个种子作校准，并要求实测均值与预测相差小于 0.35 次；还测试无关系、库存上限、登场频率、最终期限、成长保护、超员稀释、资源开关和隐藏状态隔离。

当前非攻击主持者的成长不增加普通攻击：它按 `1 + min(成长, 12) × 0.08` 增强明确标记的治疗、护盾、增幅或干扰效能，倍率类只增强超过 1 的增幅或减伤部分。培养者不接受永久培养，寒鸦的委派也不发自身成长。不同职责的收益必须分别观察，不能把支援格显示的威力数字误当治疗量，也不能声称所有委派都有相同进攻回报。
