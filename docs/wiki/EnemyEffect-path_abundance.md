[首页](Home) › [敌方条款](Enemy-Effects)

> 丰饶角色的治疗降低 25%。

| 识别码 | `path_abundance` |
| 来源 | 难度入关条款或首领分期追加 |
| 持续 | 当前遭遇；换关清空 |
| 重复 | 同 id 不重复随机选中 |

## 获得资格

编队存在丰饶角色。

除固定污染外，资格只决定选取时的候选池，条款出现后仍按自身实际触发条件运作。完整抽选和资格口径见[敌方条款通则](Enemy-Effects)。

## 实际效果与公式

丰饶角色来源的治疗请求量乘 0.75。

最终仍只记实际恢复生命，溢出另按具体技能处理；与娜塔莎专属税、全局医疗折价乘算。
