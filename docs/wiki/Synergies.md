# 羁绊

[首页](Home) › [机制索引](Mechanics)

羁绊由公开的阵营、命途、属性激活。当前共有 **21** 项；没有隐藏“套路”成型奖励。它们先检查编队身份，再按各条规则检查实际登场、位置、轮次或击破。

## 激活人数与实际登场

编队计数的算法是：筛掉 temporary 与 commission 实例，再按角色 id 去重，最后统计公开标签相符的身份数。重复副本、二星/三星不额外加人数；见习委派和临时援军不增加激活人数。达到高档门槛后直接使用高档效果，低档不会继续叠加。

羁绊激活不代表每次都有效。除公司入关预算等明确例外，仍要实际抽中相应来源或满足同场条件。每次转动抽出棋盘后、委派消耗前，先固定本次使用的激活羁绊列表；即便某个普通受体随后被委派离队，本次转动仍沿用该列表，下次再重新计算。被消耗者不继续贡献本轮登场条件或技能。

“不同身份同场”按 id 去重。“非临时”筛选在当前实现中是排除 temporary 和 expired，**没有自动排除 commission**。因此见习不增加编队激活人数，但可作为已激活羁绊的同场身份，或作为成员触发来源。普通 present 条件未排临时；如仙舟、存护、丰饶、虚数、记忆，只要相符的未消耗角色确实在场即可。各条目说明具体筛选。

## 共用公式与作用范围

各条目使用：

- `S`：来源当前星级倍率，通常一星/二星/三星为 `1 / 3 / 9`；升星差额税使高星有效倍率再乘 0.8。
- `P`：来源本轮已算出的最终威力，包含其适用成长、平加、倍率与条款；追加伤害随后仍走命中装甲/易伤公式。
- `O`：羁绊进攻系数，`(持有香涎干酪 ? 1.5 : 1) × (有羁绊征收 ? 0.75 : 1)`。二者并存为 1.125。

O 只修正羁绊 power、damage，以及 powerMultiplier 超过 1 的部分；护盾、治疗、减伤、信用点、次数与持续时间不会随之放大。直接增加威力或伤害的羁绊效果统一限制受益者/发动者为攻击职能且非辅助攻击方式；没有把辅助转为直接输出的隐藏机制。

本轮威力、减伤在轮末清空；护盾和信用点是可保留资源，仍受自身上限与消耗规则约束。普通攻击触发的击破效果不被角色或羁绊追加伤害递归触发。位置、最强目标、伤害与辅助乘区分别见[棋盘与目标](Board-and-Targeting)、[战斗](Combat)、[效果时序](Effects-and-Timing)。

## 同场概率的复原方法

AI 可计算“至少 1–3 种不同身份被抽中”的精确无放回概率；这不消耗种子随机数，也不把上一轮棋盘当下一轮结果。设编队总实例 N，抽取 d=min(20,N)，匹配标签的身份 j 拥有 n_j 份，非匹配实例 B=N−Σn_j。定义 `Q(a)=C(a,d)/C(N,d)`，a<d 时为 0。

无匹配身份概率为 `p0=Q(B)`；恰有一种为 `p1=Σj[Q(B+n_j)−Q(B)]`；恰有两种为 `p2=Σj<k[Q(B+n_j+n_k)−Q(B+n_j)−Q(B+n_k)+Q(B)]`。至少 1/2/3 种分别是 `1−p0`、`1−p0−p1`、`1−p0−p1−p2`，结果夹在 0–1。正式羁绊最多使用三身份同场门槛；函数对更高门槛的备用近似不是本版新增规则。

重复副本只提高对应身份被抽中的概率，不增加不同身份数。条件还可能要求位置或敌人状态；满足同场身份概率不等于完整技能触发概率。
