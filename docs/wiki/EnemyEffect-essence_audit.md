# 精华缓释

[首页](Home) › [敌方条款](Enemy-Effects)

> 尚未触发的精华进度获取降低 25%。

| 项目 | 规则 |
| --- | --- |
| 识别码 | `essence_audit` |
| 来源 | 难度入关条款或首领分期追加 |
| 持续 | 当前遭遇；换关清空 |
| 重复 | 同 id 不重复随机选中 |

## 获得资格

已持有至少一个尚未触发的精华。

除固定污染外，资格只决定选取时的候选池，条款出现后仍按自身实际触发条件运作。完整抽选和资格口径见[敌方条款通则](Enemy-Effects)。

## 实际效果与公式

本轮未触发精华的新进度获取量乘 0.75。

已有进度保留；与 essenceProgressMultiplier 被动相乘。先对全部精华用本轮完成时的快照结算进度，再领取触发奖励；不让同轮刚解锁的奖励反过来放大本轮其他精华进度。
