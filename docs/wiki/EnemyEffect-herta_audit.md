# 黑塔转动折损

[首页](Home) › [敌方条款](Enemy-Effects)

> 黑塔周期技能的追加伤害降低 50%。

## 获得资格

编队存在 [黑塔](Card-1013)。

除固定污染外，资格只决定选取时的候选池，条款出现后仍按自身实际触发条件运作。完整抽选和资格口径见[敌方条款通则](Enemy-Effects)。

## 实际效果与公式

[黑塔](Card-1013) 的角色 damage 技能伤害乘 0.5。

当前黑塔周期追击受此税，普通攻击不直接乘 0.5；若追击登记同时存在则伤害量乘 0.375。
