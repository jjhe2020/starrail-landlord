## 常规攻击与成长

- 无修正的1/2/3星基础威力：**0.35 / 1.05 / 3.15**。非攻击主职能：成长不加入攻击威力；仅 scaleWithTraining=true 的专职技能按每点8%、最多12点增强。
- 支援形态不执行常规攻击；它仍有威力数值，供最强目标、技能或机制读取。完整命中、装甲、易伤、四舍五入见[战斗](Combat)。

### 技能 1：获得护盾

相邻有量子或同谐伙伴时获得5护盾

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 获得护盾（`shield`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 相邻八格中符合筛选的实例数（（属性为[量子](Synergy-quantum) 或 命途为[同谐](Synergy-harmony)），且排除来源同一 UID 实例）≥1 |
| 目标 | 列车共享生命、护盾或转动资源；`target` 元数据不将共享资源复制为每位队友一份 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 5 × 星级倍率[1 / 3 / 9] × T |
| 持续 | 进入共享资源存量，保留至消耗、衰减或上限截断 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 经过护盾倍率与折价后加入护盾，存量上限为生命上限×2；实际获得量用于本轮护盾进度。
- 无升星差额税时，1/2/3星技能系数分别为1 / 3 / 9；若星级审计生效，高星系数额外×0.8。
- T=1+0.08×min(12,max(0,来源成长))，最大1.96；攻击主职能的T恒为1。倍率效果只放大相对1的部分。

### 技能 2：反击倍率削减

同行至少2名其他量子或存护伙伴时，本轮敌人反击×0.88

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 反击倍率削减（`retaliationMultiplier`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 同行其他格中符合筛选的实例数（（属性为[量子](Synergy-quantum) 或 命途为[存护](Synergy-preservation)），且排除来源同一 UID 实例）≥2 |
| 目标 | 本轮共享战斗上下文（敌方反击或装甲规则） |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | max(0.05, 1 + (0.88 − 1) × T) |
| 持续 | 本次转动；下次重算 |
| 叠加元数据 | `multiplicative`；实际加法、乘法与上限见下列结算规则 |

- 反击倍率同类相乘，平减后应用；最终倍率保底0.4，即倍率阶段最多减伤60%。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。
- T=1+0.08×min(12,max(0,来源成长))，最大1.96；攻击主职能的T恒为1。倍率效果只放大相对1的部分。

## 正式委派关系

- **太卜司轮值交接**：主持[符玄](Card-1208) → 受体[青雀](Card-1201)。主持者每3次登场可结案一名合格相邻受体；永久成长+0.35（1/2/3星×1/1.5/2）、信用点+2。每4次登场在已解锁该受体身份后补充见习。

受体保护、选择顺序和完整条件见[委派系统](Assignments)，以[src/retirements.js:3–37](https://github.com/jjhe2020/starrail-landlord/blob/e5557f8d6b3ee0a0c308c5a3ca0481d3701db229/src/retirements.js#L3-L37)及[src/engine.js:440–482](https://github.com/jjhe2020/starrail-landlord/blob/e5557f8d6b3ee0a0c308c5a3ca0481d3701db229/src/engine.js#L440-L482)为准。
