# 扩散限额

[首页](Home) › [敌方条款](Enemy-Effects)

> 扩散攻击角色威力降低 20%。

| 项目 | 规则 |
| --- | --- |
| 识别码 | `attack_blast` |
| 来源 | 难度入关条款或首领分期追加 |
| 持续 | 当前遭遇；换关清空 |
| 重复 | 同 id 不重复随机选中 |

## 获得资格

编队存在扩散攻击方式角色。

除固定污染外，资格只决定选取时的候选池，条款出现后仍按自身实际触发条件运作。完整抽选和资格口径见[敌方条款通则](Enemy-Effects)。

## 实际效果与公式

扩散攻击方式角色本轮最终威力乘 0.8。

主目标和两侧扩散都使用被削减的威力；不会删除扩散侧击。
