## 战斗对象与基本量

玩家保有一列车的公共生命和护盾。角色没有独立生命、受伤状态、能量条或战斗死亡；敌人按列各有生命和攻击。角色完成攻击后，所有存活敌人合并反击列车。角色离队另见[委派](Assignments)及[临时角色](Growth-and-Stars#临时角色与退场)。

| 量 | 含义 | 是否跨转动保留 |
| --- | --- | --- |
| 基础威力 `power` | 内容表中每种角色的固有数值 | 规则常量 |
| 永久成长 `growth` | 具体角色实例的投资；攻击者加威力，支援者放大指定职能 | 是 |
| 本次最终威力 `P` | 本次抽中并结算后，平加、倍率、条款共同作用的结果 | 仅保留上次记录，下次重算 |
| 实际伤害 | 真正扣除的敌人生命；不含溢出 | 是，体现于敌人剩余生命 |
| 生命 `H` / 上限 `Hmax` | 开局 `100 / 100`；生命耗尽即失败 | 是 |
| 护盾 `Q` | 开局 0；通常先抵伤，上限 `2 × Hmax` | 是，跨关保留 |

属性、命途、阵营和职能是公开筛选标签。本作没有一套由“火克冰”等关系自动生成的属性克制、抗性、暴击、防御力、削韧、弱点击破或敌方护盾系统。技能名中的“击破”在规则中指**将敌人的生命降到 0**；“反击”等名字也要按条目给出的触发时点理解。

支援角色仍会形成一个计算威力和威力分解，但 `attack: support` **不进行普通攻击**。因此全队威力之和不是全队伤害，也不能把培养后的支援威力当成一名攻击者。

## 最终威力公式

本版本 90 个角色均使用当前职能套件 `kitVersion: 6`。引擎保留的旧角色专用分支不会在这些条目上运行，例如旧版刃的无条件自伤或旧版青雀随机四倍不属于本版规则。

定义两位小数舍入函数：

```text
R(x) = Math.round(x × 100) / 100
S(一星, 二星, 三星) = (1, 3, 9)
若存在“升星差额税”且星级 > 1：S ← 0.8 × S
G = 实例 growth（仅攻击职能）；其他职能为 0
```

当前角色的计算可写为：

```text
B = 基础威力 × S + G + 委派当轮威力奖励 + 硬编码平加项
P = R((B + 所有已成立的临时平加) × M)
M = 效果队列中的倍率积
    × 适用奇物倍率 × 已触发精华倍率
    × 本轮大乐透倍率 × 敌方威力条款倍率
    × 待用超频倍率 × 本轮中列禁锢倍率
```

永久成长本身不乘 `S`。例如基础威力 2、二星、成长 4 的攻击者，未经其他增益时为 `2 × 3 + 4 = 10`，并非 `(2 + 4) × 3 = 18`。

平加与倍率分别收集：队列中的平加都进入 `powers`，倍率进入独立乘数，最后才乘到威力上。倍率先被排入队列，不代表后来的平加不会吃到该倍率。条件成立、目标选取和各来源的执行顺序仍很重要，见[时序](Effects-and-Timing)。

### 增幅者的倍率池

对某一个受体，来自当前角色中 `role: amplifier` 的 **`powerMultiplier` 效果**共享一个最高 **×2.2** 的池。它不限制攻击者自己的倍率、奇物倍率、精华倍率或羁绊倍率。

对一条原始倍率 `a`，若来源的可培养倍率为 `T`，先按[培养公式](Growth-and-Stars#职能培养倍率)得到：

```text
a1 = max(0.05, 1 + (a - 1) × T)     // 仅标有 scaleWithTraining 的效果
b = 适用 buffMultiplier 的积
    ×（持有纯美骑士精神 ? 1.5 : 1）
    × 角色增幅职能条款倍率
a2 = max(1, 1 + (a1 - 1) × b)
增幅池下一值 = min(2.2, 增幅池当前值 × a2)
```

因此布洛妮娅的 ×1.5，在培养 5 点（`T=1.4`）、纯美骑士精神生效时变为：`1 + (1.5 - 1) × 1.4 × 1.5 = 2.05`。若再有另一名增幅者，该受体的合计角色增幅最多达到 ×2.2。

同谐隔离 `×0.7` 与邻接隔断 `×0.6` 削减的是高于 1 的增量。上例若两者同时成立，则为 `1 + 0.5 × 1.4 × 1.5 × 0.7 × 0.6 = 1.441`，不是把整段 `2.05` 再乘两次折价。

引擎将“角色主职为增幅”或“效果目标为 `adjacent` / `strongest`”的威力效果识别为支援增益。平加项对其加值乘同一 `b`；非角色来源不额外乘角色职能条款。这个判定比一句“相邻辅助平加提升”更宽：**纯美骑士精神也放大现代增幅者的倍率增量**。

## 普通攻击

每个格子按索引从小到大出手。所有普通攻击完成后，才进入一般攻击后追加伤害；普通击杀当场触发的效果除外。每名角色出手时重新寻找存活目标，见[寻敌](Board-and-Targeting#普通攻击寻敌)。

| 攻击形状 | 未计易伤、装甲及生命截断的伤害 |
| --- | --- |
| 单体 `single` | 最近存活主目标 `3P`，仅一次 |
| 扩散 `blast` | 实际主目标 `2P`；其相邻列的每个存活敌人各 `P` |
| 群攻 `aoe` | 每个存活敌人各 `P` |
| 支援 `support` | 不产生普通攻击 |

扩散按**实际主目标**左右相邻的列计算；不会跨空列补找另一个副目标。敌人全部存活时，一名位于中间列的扩散攻击者理论总倍率可为 `2+1+1=4`，两端主目标为 3；若仅有一个敌人，只有 `2P`。群攻总倍率为当前存活敌人数，清掉某列后后续群攻的目标数随之减少。

### 每次命中的实际伤害

```text
V = min(0.75, 对本次攻击者成立的易伤增量之和)
A =（敌方技能为装甲校验且本次未无视装甲 ? 1 : 0）
D = R(min(目标当前生命, max(0, 本次输入伤害 × (1 + V) - A)))
目标生命 ← R(max(0, 目标生命 - D))
```

本次输入伤害可能为 `3P`、`2P`、`P`，或具体追加效果给出的数值。装甲**每命中一次扣 1**，不是从本轮伤害总和只扣一次，也不是按百分比减伤。一次扩散打中三名敌人，会分别扣 1；低于 1 的伤害可完全被装甲抵消。无视装甲跳过这一个平减，不改变其他倍率。

实际伤害不计溢出，击破所需伤害可以超过敌人剩余生命。目标只剩 5 生命、计算命中 60 时，伤害统计为 5；之后同列不再视为存活目标。

### 易伤的精确范围

本作易伤在效果触发时捕获符合**空间范围和公开标签**的攻击者实例 UID，形成只持续本轮的列表。它不是直接给所有敌人一个全局状态。

实际命中时，只有同时满足以下条件才用易伤：

1. 攻击者主职为 `attack`。
2. 普通攻击，或明确归属该攻击实例的角色／羁绊追加伤害。
3. 该实例 UID 在易伤捕获列表中，且仍符合该条易伤的筛选条件。

多条符合项相加，上限 `+75%`，即伤害倍率最高 ×1.75。它独立于 ×2.2 的角色增幅池。奇物造成的全局追加伤害不冒领某格角色的易伤；支援者自身也不会因此成为攻击者。

例如 `P=10` 的单体，匹配易伤合计 40%，敌方有装甲，则实际输入为 `30 × 1.4 - 1 = 41`；目标至少有 41 生命时统计 41。若易伤合计 100%，只算 `30 × 1.75 - 1 = 51.5`。

## 追加伤害与击破触发

追加伤害由各条目的 `damage` 效果定义，**不自动套用普通攻击的单体 ×3 或扩散 ×2/×1**。例如“追加自身威力的 50%”通常先得到 `0.5P`，再按该效果的目标规则命中，而不是 `0.5 × 3P`。

| 声明 | 执行含义 |
| --- | --- |
| `per.metric: sourcePower` | 数值乘当前作用实例的最终威力 |
| `scaleWithSourcePower` | 在份数、星级等缩放后，再乘来源最终威力 |
| `target: team` / `all` | 各存活敌人分别承受同一输入数值 |
| 其他一般伤害目标 | 从作用实例所在列找最近存活敌人；全局无位置来源默认以中列找目标 |
| `target: strongest` | 先选中本轮指定范围内最强受体，再沿该受体所在列寻敌 |
| `excludeOriginColumn` | 从候选敌人中剔除来源格对应列，再找最近目标 |

角色追击的敌方折价见[敌方条款](Enemy-Effects)。追加伤害仍经过每次命中的装甲、适用易伤和剩余生命截断。

**常规击破**：只有普通攻击调用的击杀回调会触发 `kill` 类效果，包括希儿再现、巡猎羁绊、击破得信用点等。它们在该次普通击破后立即执行。追加伤害击破敌人不会递归触发另一轮 `kill`；即使再现击破第二个敌人，也不靠这一条再现无限连锁。

`oncePerSpin` 按来源实例、效果和受益成员分别记录；巡猎类限定效果不会因同一实例多次普通击破无限触发。最终的整轮击破计数会重新用“转动前存活数 − 转动后存活数”计算，包含追加伤害击破，用于精华等整轮统计。

## 治疗、护盾和溢出

### 自然治疗

角色技能先算自身星级、培养、人数与角色治疗条款，再交给自然治疗入口。奇物、羁绊等没有角色来源的治疗不套用某个角色的命途专用折价。

```text
治疗请求 = R(入口数值 × 治疗倍率积)
实际治疗 = min(Hmax - H, 治疗请求)
H ← R(H + 实际治疗)
溢出治疗 = 治疗请求 - 实际治疗
```

自然治疗倍率积包括丰饶火漆 ×1.5、所有适用 `healMultiplier`、医疗折价 ×0.75。角色还可先受丰饶限流 ×0.75、娜塔莎专用条款 ×0.5 等修正。治疗不超过上限，记录和以治疗为条件的收益按**实际恢复量**计算。

普通治疗的溢出直接损失；只有 `healOverflowShield` 等明确规定溢出转盾的效果会使用溢出。转盾会再次进入自然护盾入口，接受护盾倍率和上限，因此“治疗倍率”与“护盾倍率”可以在这条转换链的两个阶段分别生效。

例：当前 `98/100`，治疗请求 6，则恢复 2、溢出 4。若效果允许溢出转盾且自然护盾倍率 ×1.5，则这 4 点溢出生成 6 点护盾，再检查护盾容量。

### 自然护盾

```text
Q新 = R(min(2 × Hmax, Q + 入口数值 × 护盾倍率积))
实际获得护盾 = R(Q新 - Q)
Q ← Q新
```

自然护盾倍率积包括存护火漆 ×1.5、所有适用 `shieldMultiplier`、已达标存护火漆·精华 ×1.3、护盾折价 ×0.75。角色先受存护折旧 ×0.75、三月七专用条款 ×0.5 等修正。多条自然护盾来源依次进入同一个容量池；容量用完后，后续发放的实际获得量为 0。

例：`Hmax=100`、已有盾 199，技能计划加 30，实际只增加 1。存护精华进度也只增加该次实际获得的 1；不把上限外的 29 作为生成或浪费前的有效盾。

[信用点补给](Economy)的维修 18、护盾 20 使用**固定入口**，不接受上述自然治疗／护盾倍率和敌方相应折价，仍接受生命／盾容量上限。禁用主动防御规划也不会关掉自然技能与承伤。

护盾跨转动和关卡保留；护盾滞纳金在抽棋盘前把已有盾变为 `R(Q×0.8)`，当轮之后新产生的盾不被这次起始衰减重复扣除。

## 敌方反击、减伤与贯穿

本轮所有攻击和通常追加伤害结束后，合计仍存活敌人的攻击。击破敌人会直接使其退出本轮反击总和，不需要另一个行动速度或控制检定。

```text
I0 = 存活敌人攻击之和
若还有存活敌人：
    战意积蓄且本关 round % 3 == 0：I0 += 3
    能量抽取且本关 round % 2 == 0：I0 += 3
F = 所有成立的反击平减之和
K = 所有成立的反击倍率之积
I = R(max(0, I0 - min(I0 × 0.45, F)) × max(0.4, K))
```

**先平减、再乘减**。平减最多扣原始反击 45%；乘减部分的合计倍率最低 0.4。两个上限独立：如果两者都达到最大，最后可到 `I0 × 0.55 × 0.4 = 0.22I0`，并非总伤害只能减至原始的 40%。

例：`I0=30`、平减 `F=20`、乘减 `K=0.2`：先最多平减 13.5，再乘保底 0.4，得到 `I=6.6`。

然后由护盾与生命结算：

```text
贯穿量 =（贯穿反击条款存在 ? I × 0.25 : 0）
抵挡量 = min(Q, I - 贯穿量)
Q ← R(Q - 抵挡量)
H ← R(max(0, H - I + 抵挡量))
```

贯穿反击在减伤后计算，所以它是**最终反击的 25%**绕过护盾，而非原始反击的 25%。该条款不会销毁等量护盾；护盾保留其未使用的部分。没有“先破盾才贯穿”的门槛。

例：`I=20`、盾 100：普通反击耗盾 20、失血 0；贯穿条款下耗盾 15、失血 5。盾只有 8 时，两种情况都只挡 8、失血 12，因为盾量不足以覆盖可抵挡部分。

污染直接扣血、奇物自伤等不经过此反击入口，通常不消耗护盾。条目写“最低留 1”的自伤不会致死，污染的直接扣血可以致死。

反击扣血后，只有列车仍存活才触发 `afterRetaliation` 效果。存护羁绊可按本轮**真实护盾抵挡量**追加伤害；它不能复活已经被反击打到 0 的列车。若这种反击后追加清掉最后敌人，本轮可以清关。

## 统计、舍入与终局边界

| 字段 | 统计范围 |
| --- | --- |
| `lastSpin.total` | 棋盘最终威力之和，包含支援格的计算威力，不等于伤害 |
| `lastSpin.damage` | 本轮所有实际敌方生命损失之和；包含追加、反击后效果 |
| `lastSpin.incoming` | 已经应用角色等减伤、尚未用护盾抵挡的最终反击 |
| `lastSpin.healing` | 此记录期间实际恢复生命之和，不含溢出 |
| `lastSpin.shield` | 此记录期间实际获得护盾之和，不等于回合末剩余盾 |
| `lastSpin.values` | 每个格子的最终威力；空格或被消耗的格子为 0 |

最终威力和每次命中分别按 `R` 舍入；实际伤害累加时也舍入。不能仅把整轮的未舍入理论总伤害最后取两位来代替逐次结算。护盾入口在新总盾值处舍入，治疗在请求数值和回写生命时舍入；成长每次加到实例后舍入。精华进度在每次结算时舍入。反击后效果读取的 `blocked` 与 `hpLost` 指标先分别按两位舍入；贯穿的原始抵挡运算则使用当时未再单独舍入的抵挡量。比较阈值时使用当前实际数值，`≤` 包含边界。

本轮生命已归 0 时失败，即使最后一名敌人也归 0，生命失败优先。若仍有敌人而剩余转动为 0，同样失败；最后一次转动清掉敌人且列车仍活着可以过关。完整状态转换见[旅程流程](Run-Flow)。

`lastSpin` 还可能在奖励取得或进入下一关时追加即时记录；应核对事件自带的关卡和转动数，不能只把页面上仍显示的上一轮棋盘视为这些新事件的发生位置。记录是展示证据，不会在读档时重新执行。
