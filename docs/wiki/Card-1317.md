## 常规攻击与成长

- 无修正的1/2/3星基础威力：**2.5 / 7.5 / 22.5**。攻击主职能：成长直接加入基础威力，不被1/3/9星级再乘。
- 常规攻击命中所有存活敌列，每列系数1。完整命中、装甲、易伤、四舍五入见[战斗](Combat)。

### 技能 1：威力平加

相邻有虚数或智识伙伴时，每列存活敌人使本次威力+0.35，最多5列

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 威力平加（`power`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 相邻八格中符合筛选的实例数（（属性为[虚数](Synergy-imaginary) 或 命途为[智识](Synergy-erudition)），且排除来源同一 UID 实例）≥1 |
| 目标 | 来源实例自身 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 0.35 × min(5, max(0, 当时存活敌列数)) × 星级倍率[1 / 3 / 9] |
| 持续 | 本次转动；下次重算 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 在本次威力平加段结算，再经过适用最终乘区；不会增加永久成长。
- 份数不向下取整；除法结果可为小数，再受cap截断。
- 无升星差额税时，1/2/3星技能系数分别为1 / 3 / 9；若星级审计生效，高星系数额外×0.8。
