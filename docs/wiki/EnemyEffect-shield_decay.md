# 护盾滞纳金

[首页](Home) › [敌方条款](Enemy-Effects)

> 每次转动开始时，已有护盾减少 20%。

| 项目 | 规则 |
| --- | --- |
| 识别码 | `shield_decay` |
| 来源 | 难度入关条款或首领分期追加 |
| 持续 | 当前遭遇；换关清空 |
| 重复 | 同 id 不重复随机选中 |

## 获得资格

与护盾折价相同：已有护盾或存在可用的持续护盾来源。

除固定污染外，资格只决定选取时的候选池，条款出现后仍按自身实际触发条件运作。完整抽选和资格口径见[敌方条款通则](Enemy-Effects)。

## 实际效果与公式

每次转动开始、抽棋盘之前，已有护盾改为 `round2(护盾 × 0.8)`。

本轮随后新生成护盾不会在同一开轮再衰减；这一损失不算护盾抵挡，不触发存护抵伤反击。若首领轮数分期在本轮开始新增此条款，会立即衰减。
