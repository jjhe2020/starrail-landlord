## 常规攻击与成长

- 无修正的1/2/3星基础威力：**2 / 6 / 18**。攻击主职能：成长直接加入基础威力，不被1/3/9星级再乘。
- 常规攻击向来源列最近存活敌列命中1次，系数3。完整命中、装甲、易伤、四舍五入见[战斗](Combat)。

### 技能 1：威力倍率

相邻有星穹列车或同谐伙伴时，本次威力×1.4

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 威力倍率（`powerMultiplier`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 相邻八格中符合筛选的实例数（（阵营为[星穹列车](Synergy-astral) 或 命途为[同谐](Synergy-harmony)），且排除来源同一 UID 实例）≥1 |
| 目标 | 来源实例自身 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 1.4 |
| 持续 | 本次转动；下次重算 |
| 叠加元数据 | `multiplicative`；实际加法、乘法与上限见下列结算规则 |

- 与其他适用威力倍率相乘；自身条件倍率不占即时增幅角色共同×2.2的上限。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。

### 技能 2：永久成长

每第4次登场且相邻有星穹列车或同谐伙伴，自身永久成长+0.15

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 永久成长（`growth`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 相邻八格中符合筛选的实例数（（阵营为[星穹列车](Synergy-astral) 或 命途为[同谐](Synergy-harmony)），且排除来源同一 UID 实例）≥1 |
| 目标 | 来源实例自身 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 0.15 |
| 持续 | 本局；新局不继承 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 写入编队中同UID且非临时的原实例；通用入口本身不排除见习或培养主职，目标筛选另行决定是否排除它们。例如丹恒见习可以触发自身成长，但专业培养者的受体筛选排除见习。新成长再乘齿轮、成长折旧和适用成长倍率；两位小数保存，本轮攻击威力/可培养技能即可使用更新后的成长。成长赠送量不会被来源自己的培养倍率放大。
- every=4：appearance使用该实例已加1后的ticks，其余触发使用本关round；计数必须>0且整除。不会按全局总转动数计算。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。

- **智库外勤归档**：主持[瓦尔特](Card-1004) → 受体[丹恒](Card-1002)。主持者每3次登场可结案一名合格相邻受体；永久成长+0.35（1/2/3星×1/1.5/2）、信用点+2。每4次登场在已解锁该受体身份后补充见习。
