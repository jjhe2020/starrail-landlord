## 常规攻击与成长

- 无修正的1/2/3星基础威力：**2.5 / 7.5 / 22.5**。攻击主职能：成长直接加入基础威力，不被1/3/9星级再乘。
- 常规攻击向来源列最近存活敌列命中1次，系数3。完整命中、装甲、易伤、四舍五入见[战斗](Combat)。

### 技能 1：独立追加伤害

每第2次登场且相邻有记忆或翁法罗斯伙伴，衣匠追加自身威力65%的双人攻击

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 独立追加伤害（`damage`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 常规攻击之后；按统一时序结算 |
| 门槛 | 相邻八格中符合筛选的实例数（（命途为[记忆](Synergy-remembrance) 或 阵营为[翁法罗斯](Cards#faction)），且排除来源同一 UID 实例）≥1 |
| 目标 | 寻找来源格对应列；空列改找最近存活敌列；距离相同时取左侧 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 0.65 × max(0, 所选来源格的最终威力) |
| 持续 | 本次转动；下次重算 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 每个目标敌列独立执行命中、易伤、装甲和剩余生命截断；追加伤害不递归触发常规击破追击。转动内造成的伤害与实际击破计入本轮总伤害和最终击破敌列数。读取 sourcePower 的效果会在真正追加结算时重读最终威力。
- every=2：appearance使用该实例已加1后的ticks，其余触发使用本关round；计数必须>0且整除。不会按全局总转动数计算。
- 份数不向下取整；除法结果可为小数，再受cap截断。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。

### 技能 2：召唤临时角色

每第4次登场且同行有其他记忆或翁法罗斯伙伴，召来临时素裳，下次起可抽中，登场2次后离队

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 召唤临时角色（`summon`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 同行其他格中符合筛选的实例数（（命途为[记忆](Synergy-remembrance) 或 阵营为[翁法罗斯](Cards#faction)），且排除来源同一 UID 实例）≥1 |
| 目标 | [素裳](Card-1206)的新一星临时实例，加入编队，下一轮起可能抽中 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 1 |
| 持续 | 临时实例的实际登场次数 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 新实例为一星、成长0，实际登场寿命=2次；编队加本轮待生成实例达到200时不生成。其出生当轮不能加入已抽好的棋盘；临时身份不计正式羁绊，不参与普通三合一。
- every=4：appearance使用该实例已加1后的ticks，其余触发使用本关round；计数必须>0且整除。不会按全局总转动数计算。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。
