### 技能 1：治疗并将溢出转为护盾

相邻有虚数或毁灭伙伴时恢复6生命，溢出转为护盾

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 治疗并将溢出转为护盾（`healOverflowShield`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 相邻八格中符合筛选的实例数（（属性为[虚数](Synergy-imaginary) 或 命途为[毁灭](Synergy-destruction)），且排除来源同一 UID 实例）≥1 |
| 目标 | 列车共享生命、护盾或转动资源；`target` 元数据不将共享资源复制为每位队友一份 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 6 × 星级倍率[1 / 3 / 9] × T |
| 持续 | 进入共享资源存量，保留至消耗、衰减或上限截断 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 请求治疗先经过治疗倍率与折价并四舍五入到两位小数；实际恢复=min(缺失生命, 请求值)。溢出=请求值−实际恢复，随后按护盾入口再应用护盾倍率与上限。
- 无升星差额税时，1/2/3星技能系数分别为1 / 3 / 9；若星级审计生效，高星系数额外×0.8。
- T=1+0.08×min(12,max(0,来源成长))，最大1.96；攻击主职能的T恒为1。倍率效果只放大相对1的部分。
