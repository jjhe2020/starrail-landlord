## 每一个副本都是什么

招募或生成的角色是独立实例，通常初始为：

```text
uid = 下一唯一实例编号
id = 角色内容 ID
stars = 1
growth = 0
ticks = 0
```

`uid` 用于区分两个同名副本、污染指定实例、记录技能来源以及定向成长。`id` 决定当前公开标签、主职和技能；同一实例的星级不会改变其阵营、命途或技能对象名单。

`growth` 统一保存永久投资；攻击者称永久攻击成长，支援者称职能培养。`ticks` 是该实例实际成功参加登场处理的次数，跨转动和关卡保留；未抽中不增加。委派在登场处理之前完成，被委派离队的受体不会增加本次 `ticks`，也不再给登场技能或普通攻击。

## 三合一自动升星

每次招募把新角色加入编队后，自动执行：

1. 先检查所有角色的一星副本，再检查二星副本。
2. 相同角色 ID、相同星级的**三个正式非临时、非见习委派副本**合成一个更高星实例。
3. 该角色如果还有三份同星继续合成；所有二星结果还可以继续三合一成为三星。
4. 三星封顶，没有三星再合成四星。

同星候选按编队中的现有顺序取前三个；不会自动为玩家选择“成长最低的三个”。生成的临时援军、见习委派不会参与合成，不能用免费见习加两张正式副本凑三合一。合成发生于招募结算，普通转动中的生成不会自动触发该过程。

| 项目 | 合成后的结果 |
| --- | --- |
| `uid` | 创建全新 UID；三个旧 UID 从编队删除 |
| `stars` | 原星级 +1 |
| `growth` | 三个副本的成长求和后保留两位小数 |
| `ticks` | 三个副本中**最大**的登场次数，不求和，也不归零 |
| 技能 | 继续使用该角色当前定义；星级仅放大声明允许的部分 |
| 污染 | 如果被污染的旧实例因合成消失，其标记解除 |
| 统计 | 每组三合一累计 `merges+1`，触发该次 `merge` 事件 |

例如三名丹恒成长为 1、2、0.5，登场次数 3、7、4，合成后为二星、成长 3.5、次数 7。下一次真正上场时次数升为 8，可以满足“每第 4 次登场”；不是把三人次数加为 14。

九张一星可以先得到三个二星，再得到一个三星；共发生 **4 次合成事件**。若其中八张已有成长 1，新招募第九张成长 0，最终三星成长为 8。

### 星级倍率和技能缩放

| 星级 | 标准倍率 `S` | 有升星差额税时 | 培养发放／当前委派成长的温和倍率 `F` | 有升星差额税时的 `F` |
| --- | --- | --- | --- | --- |
| 一星 | 1 | 1 | 1 | 1 |
| 二星 | 3 | 2.4 | 1.5 | 1.2 |
| 三星 | 9 | 7.2 | 2 | 1.6 |

基础威力总是用标准星级倍率。技能数值只有声明 `scaleWithStars:true` 才使用来源星级缩放；`starFactors:[0,1,1.5,2]` 则用温和表替换标准表，仍承接升星差额税的 0.8 折价。

**概率、条件阈值、受益人数上限、登场周期、未声明缩放的倍率或易伤不会自动乘 3 或 9。** 例如布洛妮娅的 ×1.5 增幅没有星级缩放，升二星并不直接变为 ×4.5；丹恒未声明星级缩放的自成长仍是每次符合条件增加 0.15。

星级税只改受它控制的星级量，不把当前已存的成长整体扣 20%，也不会降回一星；成长在攻击基础中的平加仍保留。二星攻击者成长 4、基础威力 2，有税时先算 `2 × 2.4 + 4 = 8.8`。

升星把三个占格副本压成一个，也会改变上场稀释、相邻人数和技能覆盖。基础攻击倍率按 1/3/9 保留三份基础量，但三个人各自提供的邻接机会、培养次数和上场位置不会自动搬进新副本。不能单凭基础倍率宣称升星对所有阵容都等量提升。

## 永久成长怎样发放

普通数据成长的入口为：

```text
A = 该次效果数值
    × 明确声明的人数／份数／来源星级因子
    × 适用的角色技能专用折价
ΔG = A
    ×（持有鲁珀特帝国机械齿轮 ? 1.5 : 1）
    ×（本层成长折旧存在 ? 0.5 : 1）
    × 适用 growthMultiplier 之积
目标 growth ← R(目标 growth + ΔG)
```

万象无常骰提供自然成长 `×1.2`，可与齿轮相乘；成长折旧只影响**本层新加的量**。已有 4 点成长不会因进入折旧关变成 2。

成长必须找到编队内同 UID 的原始实例，临时受体不会写入。当前培养者声明还会排除自身、培养主职、临时者和见习委派，并限定公开标签、空间范围与人数；单纯拥有一个培养者不意味着全编队每轮都会成长。

例：驭空某次培养基础量 0.35，齿轮、无常骰和成长折旧同时生效：`ΔG=0.35×1.5×1.2×0.5=0.315`。若受体原有 4，回写 `R(4.315)=4.32`。每次回写保留两位，因此重复小额培养应逐次计算，不能等所有轮数结束才只舍入一次。

### 攻击者的成长

攻击主职将当前成长以平加形式加入基础攻击威力：

```text
攻击基础 = 固有威力 × 实际标准星级倍率 + growth
```

本次在攻击前获得的成长会被本次威力构建读到，通常不必等下一轮才得到攻击收益。成长不直接增加独立命中次数，也不改变攻击形状；但按来源最终威力计算的追击会随威力一起增加。

攻击成长没有 12 点的职能收益上限；12 点上限只属于下述非攻击职能培养。当前常规规则没有另设攻击成长软上限。

### 职能培养倍率

对当前套件的非攻击主职：

```text
T = 1 + min(12, max(0, growth)) × 0.08
```

每点成长让标为可培养的职能增量提高 8%；0 点为 ×1，5 点为 ×1.4，10 点为 ×1.8，12 点及以上均为 **×1.96**。超过 12 点的值仍保存，也能被合成继承，只是这一职能公式不再继续增长。

| 效果形式 | 可培养时如何变化 | `growth=5` 的例子 |
| --- | --- | --- |
| 治疗、护盾、平加、易伤、反击平减等普通数值 | `A × T` | 10 护盾 → 14；20% 易伤 → 28% |
| 威力倍率、反击倍率、治疗倍率、护盾倍率、增幅倍率、成长获取倍率 | `max(0.05, 1 + (A-1)×T)` | ×1.5 → ×1.7；反击 ×0.9 → ×0.86 |
| `growth` 发放 | **不乘 `T`**，即使数据声明了培养标记 | 发 0.35 仍发 0.35 |
| 没标 `scaleWithTraining` 的效果 | 不变 | 固定得 1 信用点仍是 1 |

培养只放大来源角色明确标记可培养的效能，不直接给支援者增加普通攻击。受体的成长不拿去放大别人给它的增幅；例如布洛妮娅的倍率读布洛妮娅自身培养，而不是读被增幅攻击者的成长。

当前所有专业培养者都在受体过滤中排除 `role:trainer`，因此不会靠培养者相互训练形成递归自乘。旧存档若保有某个培养者的成长，该值仍是实例数据，但不因此放大它发给别人的成长量。

培养何时影响当轮技能受[执行顺序](Effects-and-Timing)约束：已经发生的盾、治疗不因稍后补到成长而回溯增加；稍后才执行或应用队列的可培养技能可读取其更新后的成长。

### 委派带来的成长

[剧情委派](Assignments)是另一条成长来源：当前大多数关系每次结案给主人基础 +0.35 成长，寒鸦的结案成长为 0；同样使用 `1 / 1.5 / 2` 的温和来源星级表与新成长倍率。

仅攻击主职的当前委派主持还拿到 `rule.power × 实际标准星级倍率` 的当轮威力；这是临时奖励，不把它再写成永久成长。非攻击主持得到的成长增强其标明可培养的职能，不会因此产生普通攻击。具体关系、周期、保护规则和信用点见[委派](Assignments)。

## 临时角色与退场

临时援军携带 `temporary:n`，表示还可参加 **n 次实际登场**；不是在队内存在 n 轮，也不是下 n 次转动无条件减 1。

- 生成时为新一星实例、0 成长、0 登场，另有来源 `origin`；一般 `summon` 把寿命夹在 1–3。
- 当前这次结算结束才加入编队，下次抽取起可能出现；编队已达生成上限时不再生成。
- 没抽中时寿命不变。抽中且没有提前被消耗，完成登场处理后寿命 `-1`。
- 从 1 减到 0 时标记 `expired`，本轮仍可出普通攻击，也仍匹配“临时角色”加成；在整轮收尾才移出编队。
- 若提前被消耗，则跳过尚未进行的登场和攻击。消耗与自然到期都计入本轮退场，提供明确写“退场”的收益。
- 临时角色不参与升星、不计永久身份羁绊；正常技能可以对其临时威力或易伤起效，但永久成长入口跳过它们。

例如寿命 2 的援军：生成轮不在棋盘；下一次真正抽中后剩 1；若随后连续三次没抽中，仍剩 1；再一次抽中时标到期，完成最后一次攻击后移除。

临时到期和委派离队不是角色被敌人击杀；`stats.destroyed` 是历史通用退场计数，不能仅凭这个字段名把它解释成战斗死亡。主动[移除](Economy)消耗移除机会，并不触发下一次转动的 `retire` 事件。

### 见习委派与临时援军不同

见习委派携带 `commission` 而非 `temporary`，没有自动到期寿命；保留到结案或被主动移除。它们参与抽取、可以在未结案时执行角色自身技能，但不计羁绊身份、不升星，当前培养技能也排除它们。不能把见习数量当作普通永久角色身份，也不能让“只找临时角色”的效果自动选到见习。

## 容易错误复原的边界

| 误读 | 当前规则 |
| --- | --- |
| 二星所有技能数值都是三星前的三倍 | 只有基础威力和声明允许星级缩放的效果放大 |
| 专业培养者三星发放九倍成长 | 当前培养与委派成长采用温和的 2 倍 |
| 成长先乘星级再计入攻击 | 攻击基础星级放大后，成长再平加 |
| 培养让培养者下一轮培养更多人／更多成长 | 不放大发放量，不改变人数上限或周期 |
| 支援培养超过 12 后整条成长被删除 | 值保存，只有职能公式在 12 封顶 |
| 合成把全部登场次数相加 | 取三个副本最大值 |
| 临时寿命按每轮倒计时 | 只按真正抽中并处理的登场倒计时 |
| 到期者本轮立刻失去攻击 | 最后一次登场仍攻击，然后清理 |
| 旧污染随合成转移到高星结果 | 指定旧 UID 消失即解除标记 |
