## 常规攻击与成长

- 无修正的1/2/3星基础威力：**0.35 / 1.05 / 3.15**。永久培养主职能：基础威力不加成长；常规赠送培养的筛选排除培养主持，赠送量不自乘培养系数。
- 支援形态不执行常规攻击；它仍有威力数值，供最强目标、技能或机制读取。完整命中、装甲、易伤、四舍五入见[战斗](Combat)。

### 技能 1：永久成长

每第3次登场，至多2名相邻的物理或毁灭永久非培养伙伴各永久成长+0.3

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 永久成长（`growth`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 无额外数值门槛（仍需来源与触发成立） |
| 目标 | 来源相邻八格；最多2名 |
| 目标筛选 | （属性为[物理](Synergy-physical) 或 命途为[毁灭](Synergy-destruction)），且主职能不为[永久培养](Cards#role)，且非临时实例（此字段本身不排除见习），且排除见习委派，且排除来源同一 UID 实例 |
| 基础数值公式 | 0.3 × 星级系数[1 / 1.5 / 2] |
| 持续 | 本局；新局不继承 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 写入编队中同UID且非临时的原实例；通用入口本身不排除见习或培养主职，目标筛选另行决定是否排除它们。例如丹恒见习可以触发自身成长，但专业培养者的受体筛选排除见习。新成长再乘齿轮、成长折旧和适用成长倍率；两位小数保存，本轮攻击威力/可培养技能即可使用更新后的成长。成长赠送量不会被来源自己的培养倍率放大。
- every=3：appearance使用该实例已加1后的ticks，其余触发使用本关round；计数必须>0且整除。不会按全局总转动数计算。
- 无升星差额税时，1/2/3星技能系数分别为1 / 1.5 / 2；若星级审计生效，高星系数额外×0.8。

### 技能 2：资源收入

每第3次登场且相邻有物理或仙舟罗浮伙伴，获得1信用点

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 资源收入（`resource`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 相邻八格中符合筛选的实例数（（属性为[物理](Synergy-physical) 或 阵营为[仙舟罗浮](Synergy-xianzhou)），且排除来源同一 UID 实例）≥1 |
| 目标 | 信用点；`target` 元数据不将共享资源复制为每位队友一份 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 1 |
| 持续 | 进入共享资源存量，保留至消耗、衰减或上限截断 |
| 叠加元数据 | `additive`；实际加法、乘法与上限见下列结算规则 |

- 信用点收入先取max(0, 数值)；信用点保留两位小数，重掷/移除向下取整。资源存量跨轮、跨关保留。
- every=3：appearance使用该实例已加1后的ticks，其余触发使用本关round；计数必须>0且整除。不会按全局总转动数计算。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。

## 正式委派关系

- **十王司结案休假**：主持[寒鸦](Card-1215) → 受体[雪衣](Card-1214)。主持者每3次登场可结案一名合格相邻受体；永久成长+0（1/2/3星×1/1.5/2）、信用点+3。每4次登场在已解锁该受体身份后补充见习。

受体保护、选择顺序和完整条件见[委派系统](Assignments)，以[src/retirements.js:3–37](https://github.com/jjhe2020/starrail-landlord/blob/e5557f8d6b3ee0a0c308c5a3ca0481d3701db229/src/retirements.js#L3-L37)及[src/engine.js:440–482](https://github.com/jjhe2020/starrail-landlord/blob/e5557f8d6b3ee0a0c308c5a3ca0481d3701db229/src/engine.js#L440-L482)为准。
