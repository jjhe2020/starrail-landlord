## 常规攻击与成长

- 无修正的1/2/3星基础威力：**2 / 6 / 18**。攻击主职能：成长直接加入基础威力，不被1/3/9星级再乘。
- 常规攻击命中来源列最近存活敌列，系数2；再命中主目标左右紧邻列的存活敌人，各系数1，溅射不继续找远列。完整命中、装甲、易伤、四舍五入见[战斗](Combat)。

### 技能 1：威力倍率

每第3次登场且同行有其他量子或同谐伙伴，本次威力×2.35

| 字段 | 精确口径 |
| --- | --- |
| 类型 | 威力倍率（`powerMultiplier`） |
| 触发 | 来源实例实际登场时（登场计数已先加1） |
| 阶段 | 默认 beforeAttacks；被动倍率在实际收益调用处使用 |
| 门槛 | 同行其他格中符合筛选的实例数（（属性为[量子](Synergy-quantum) 或 命途为[同谐](Synergy-harmony)），且排除来源同一 UID 实例）≥1 |
| 目标 | 来源实例自身 |
| 目标筛选 | 无额外公开标签筛选 |
| 基础数值公式 | 2.35 |
| 持续 | 本次转动；下次重算 |
| 叠加元数据 | `multiplicative`；实际加法、乘法与上限见下列结算规则 |

- 与其他适用威力倍率相乘；自身条件倍率不占即时增幅角色共同×2.2的上限。
- every=3：appearance使用该实例已加1后的ticks，其余触发使用本关round；计数必须>0且整除。不会按全局总转动数计算。
- 此效果数值不随1/3/9星级倍率自动放大；来源最终威力参与的追击仍间接受星级影响。

## 正式委派关系

- **太卜司轮值交接**：主持[符玄](Card-1208) → 受体[青雀](Card-1201)。主持者每3次登场可结案一名合格相邻受体；永久成长+0.35（1/2/3星×1/1.5/2）、信用点+2。每4次登场在已解锁该受体身份后补充见习。
