# 0.6 绑定组机制与平衡证据

## 真实角色组合探针

使用当前90卡与正式引擎，10组各选防御、培养、增幅、干扰四个真实技能配置，每个配置100个独立种子；另对每组四支援无攻击配置测试100个种子。共5000个独立种子块、14000次正式单转观测，另140次正式spin一致性复算。

同一种子保留抽盘布局，对照两名同组攻击伙伴、替换为组外且同攻击范围的伙伴，以及仅给原支援增加12点培养。五列敌人各100万生命、反击各8，玩家生命100/200、无初始护盾；不带奇物、精华、条款，保留真实羁绊。支援预置11次登场，刻意让本次第12次登场对齐2/3/4周期；这是成熟条件下的机制验证，不是自然触发频率或通关率。

40个角色配置均出现实际正收益；换成不属于来源任何绑定组的同职责攻击伙伴后，目标机制均无收益。邻接型技能的未触发种子真实保留为零，不摆盘、不剔除。永久培养者加12点自身培养不增加发放量；其他支援的可培养职能提高，支援自身实际伤害和攻击威力分解中的成长始终为零。每组纯支援队伍在培养0与12时实际伤害均为零。

干扰探针另保留易伤已排队数值、匹配攻击者数量、其真实伤害和培养前后配对差；组外没有匹配攻击者时，即使易伤已经排队也不算有效收益。不同角色替换会同时改变自身技能和羁绊，因此不能把两套身份的总伤害差直接归因给某一个支援；只改变支援培养的配对在角色与布局上保持一致。

每项均保留含零样本的均值、95%区间、正收益比例的Wilson区间和逐种子结果；该固定高血、缺血、周期对齐的单转实验不能证明全程胜率、自然拿牌概率、终局强度排名或所有套路均衡。它证明上述配置中的绑定门槛、支援不可替代攻击及培养职能转化确实执行。

## 难度校准（正式留出前）

新版角色输出和职责已重做，先用60个配对校准种子比较D10敌人生命倍率；这批用于选参数，不纳入正式留出，不把同一批调参成绩当独立验收。

| D10生命倍率 | 通关/60 | 胜率 | Wilson 95%区间 |
| --- | ---: | ---: | --- |
| 1.0 | 60/60 | 100% | 93.98%–100% |
| 1.2 | 59/60 | 98.33% | 91.14%–99.71% |
| **1.4（选定）** | **56/60** | **93.33%** | **84.07%–97.38%** |
| 1.6 | 51/60 | 85% | 73.89%–91.90% |

本轮选择1.4，提高默认D10的构筑压力；同时将高段难度步长调为1.155，保留低段1.22。最终规则标识 `difficulty-v7-bound-roles`，D≥6的生命系数为 `0.35×1.155^((D−10)/2)`，D<6为 `0.35×1.155^(−2)×1.22^((D−6)/2)`；D2/D4/D6/D8/D10/D20分别约0.176272/0.215052/0.262364/0.303030/0.350000/0.719412，D20接近旧版压力。所有资源配置仍用同一曲线，固定关卡与后程增长规则不变。

[完整校准数据](benchmarks/v060-d10-calibration.json)保留各档资源、失败、选择和区间。60局只用于本轮参数取舍，样本区间较宽；0.6最终强度以冻结规则后的正式D10/D20对局另行说明，不能由校准或固定单转探针外推。
