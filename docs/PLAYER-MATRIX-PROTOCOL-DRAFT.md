# 多维玩家策略 × 难度测试协议草案 v1

状态：**2026-10-26 用户已确认1A标准方案，测试设施实施中**。方案制定日期：2026-10-25。

基准：v0.8.1，发行提交 `1b3a13b3eedf36ac1eb5f906332e62a4687ce93f`。本次执行不修改发行游戏、默认AI、资源或敌人数值，不自动发布版本。实验专用策略、记录设施与批准的对局测试属于本次范围。下文样本、参数与判断范围均为本次实验建议，不是永久游戏要求。

## 1. 这次实验需要回答什么

1. 不同队伍偏好、近期/远期取向、奖励选择随机程度与资源经营组合，在 D1–D20 上怎样生存、失败和形成构筑？
2. 压力何时出现？有无前面长期宽松、末关突然失守，或某阶段先天无解的情况？
3. 长期投资是否存在先付代价、后兑现收益的路径？只追求当前强度又付出什么代价？
4. 选择更随机是否反而更好？这来自发现新组合、避免错误估值、资源动作不对称，还是模型实现问题？
5. 在真实资源机会处忽略经营，本关或随后一两关是否出现可观察的代价？恢复规划或主动补救能否挽回？
6. 更快清场是否有明确收益？多转带来的招募、成长与精华是否会补偿甚至奖励弱经营？

不预设理想通关率，不沿用旧“95%定义D10”或“少一种资源降低两档”的约定。不把所有策略等强作为目标，也不把统计不显著当作平衡。AI可以检查这些体验的结构条件，不能单独证明真人觉得好玩。

- `src/balance-v080.js` 标签偏好重新归一时固定使用默认温度，不能直接叠加为独立随机轴。
- `src/simulation.js` 的旧 uniform 不跳过奖励、不经营资源，不能作为“只改变随机程度”的公平对照。
- 现有 growth/economy/merge 权重混合了立即收益、后续成长和资源价格；仅改 growth 不足以定义贪婪。

## 3. 可组合的玩家策略

主矩阵：`29 队伍偏好 × 3 长短期取向 × 3 奖励随机性 × 3 资源经营 = 783 种策略`。

每种策略覆盖 D1–D20，共 **15,660 个策略—难度格**。策略标签只描述行为，不增加技能、成型奖励、候选出现率或敌人惩罚。

### 3.1 队伍偏好 T：29项

沿当前内容冻结下的29项，开跑前导出完整ID、成员与筛选条件：

- 无固定偏好：1项。
- 命途9项：丰饶、同谐、存护、巡猎、智识、欢愉、毁灭、虚无、记忆。
- 属性7项：冰、火、物理、虚数、量子、雷、风。
- 阵营8项：仙舟罗浮、匹诺康尼、星核猎手、星穹列车、星际和平公司、翁法罗斯、贝洛伯格、黑塔空间站。上述单标签方向至少有5名可招募角色。
- 四个公开组合方向：巡猎或仙舟罗浮、智识或黑塔空间站、冰或贝洛伯格、虚无或星核猎手。

四个组合明确采用 **OR**，符合其中任一标签即可获得一次选择偏好，不双计分，也不写成同时具备两种标签的额外羁绊。奖励没有匹配候选时照常选择其他角色或跳过，不强制拿低效卡。

初始偏好加值建议为当前奖励候选收益尺度的0.75倍：`scale = max(1, Q75(U_without_tag) − Q25(U_without_tag))`，匹配者加 `0.75 × scale`。只影响招募偏好及与其一致的重掷预期，不改变战斗。该系数先在状态库验证和冻结，不根据通关成绩调到某方向胜出。

少于5名角色的标签、多方向试探后转型、所有两标签组合不在主矩阵中，报告列覆盖缺口，不声称覆盖所有可能队伍。

### 3.2 长短期取向 H：3项

适配器显式分解决策估值：

`U = 当前收益 N + λF × 未来增量 F + 标签偏好 T − λR × 资源机会成本 C`。

这是模拟玩家取舍的内部评分，**不作为报告的统一战力或平衡总分**。

| 取向 | λF | 行为定义 |
| --- | ---: | --- |
| 短期战力 | 0.35 | 更重当前输出、生存、立即合成与本关兑现 |
| 均衡 | 1 | 同时考虑当前风险与后续潜力 |
| 贪婪投资 | 2 | 愿意牺牲部分当前战力换取后续成长、经济或延迟组合 |

N包含立即形成的属性、输出、防御与羁绊收益；F只包含后续新增价值，例如永久成长、尚未合成的后续机会、经济被动、精华激活与持续效果。立即升星的当前收益进N，不再同时记为F。已有永久攻击力已属于当前属性，不重复当未来成长。F计算不超过本轮12关终点，终局未消费现金不凭空给予收益。

各H使用相同估值特征、公开信息、候选集和计算预算；改变的是未来收益权重。未来估计需列出收益类别和预计兑现时间，不能用“成长角色数量”代替贪婪程度。λF不直接修改C，避免把长期投资和囤积现金混成一个维度。

### 3.3 奖励选择随机性 J：3项，另设纯随机控制

主矩阵 ε取 **0、0.15、0.45**：

`p(a) = (1−ε) × 最优评分项分布 + ε × 合法奖励及跳过的均匀分布`。

并列最优公平抽取并记录。随机轴覆盖角色、奇物、精华的选择；**不声称把重掷、移除、补给也随机化**。不以降低前瞻次数、换一套估值模型或删除跳过来制造随机差异。

另设 ε=1 的纯均匀奖励控制，固定T无偏好、H均衡，分别搭配3种资源经营。为隔离奖励随机性，这组控制明确固定T/H；其余T/H×ε=1组合本轮未覆盖。纯均匀只抹掉奖励选取时的偏好，重掷和其他资源规划仍可能受到T/H影响，因此不能宣称其余组合行为等价。另保留未经修改的当前AI作为1个桥接控制。因此控制组共4项，同样覆盖D1–D20。

纯随机控制和其他策略拥有相同奖励及跳过动作，资源权限相同。旧 choose-only uniform 只可作为历史极端对照，不进入随机性因果结论。全动作随机若后续追加，需要按动作类别分配概率，不能对每个角色UID直接均匀抽样而使大编队更常被移除。

### 3.4 资源经营 R：3项

| 经营风格 | λR | 行为定义 |
| --- | ---: | --- |
| 积极投入 | 0.5 | 在有收益的机会中更早使用资源换取优势 |
| 均衡经营 | 1 | 平衡当前收益、后续机会与储备 |
| 偏重储备 | 2 | 对不可逆消费要求更高回报，更愿意留待后续 |

C统一记录重掷/移除机会、信用点与本关购买次数的机会成本；各档使用同一算法，只改变λR。医疗、护盾、超频分别估值。自然治疗和护盾始终生效；没有资源、没有改善空间或当前收益不足时，允许三档都不消费。生命/护盾是风险与储备，不是需要故意消耗的按钮。

λR不修改长期收益项F或游戏权限。主矩阵不把资源关闭等同玩家不善经营；遗漏某类资源另用中途分叉测试。原版AI只是桥接控制，不将新适配器的“均衡”冒充原版AI。

## 4. 策略必须先证明标签对应真实行为

正式跑矩阵前建立96个受控合法状态：`3阶段 × 4风险状态 × 8类决策题`。风险状态为安全、生命紧张、期限紧张、复合压力；决策题覆盖标签取舍、立即合成/留对子、成长、经济、精华延迟兑现、稀释/污染、资源稀缺与充足等。状态库与自然对局分开，不把其结果当通关证据。

所有策略使用相同预算：初始建议每候选4个公开信息反事实棋盘、重掷3组未揭示候选估计；具体运行配置、缓存方式与缺省回退开跑前冻结。不能读取真实seed、rngState或下一次奖励。

资格检查包括：

1. 同一候选中，匹配标签的选择偏好确实上升；不匹配时不凭空加成。
2. 在当前收益较低、未来收益较高的明确题目中，λF提高能够改变排序；记录N/F/T/C原始分量。
3. 同一组分数下，ε、选取最优项的概率、选择熵符合解析公式；并列最优单列，不要求所有题目必有不同动作。
4. 同一有效消费机会中，降低λR不会提高投入门槛；实际整局消费次数不要求单调，因为早清与早败也会减少消费机会。
5. 全部候选包含相同合法动作；无非法动作、输入修改、真实随机流泄漏或按策略身份改变敌人。
6. 记录器开关、单/多worker、分片大小、断点恢复不改变结果。

策略若未通过，先修适配器或标签定义；不得把没有表现出贪婪的策略直接按“贪婪玩家”统计。修正仅依据状态库和实现问题，不按胜率选参数。主实验前保存策略清单与源码哈希。

### P2问题如何选，避免只挑想证明的结论

开看P1前冻结以下名额与算法：

- 16个两策略问题：队伍偏好、长短期、随机性、资源经营各4个，只改变对应因素，其余相同。各类2个按通关差异、2个按每局清除关数差异选；分别覆盖正向和反向线索，重复问题按稳定ID去重。
- 8个交互问题：长期取向×资源经营3个、长期取向×队伍2个、随机性×队伍2个、随机性×资源经营1个。固定另两个轴，用四策略的“差异之差”确认，不能比较两个显著性标签就声称交互。
- 每问题选择信号最大的中心难度，再取D−2/D+2，边界截断并去重；胜率全在地板/天花板时按清除关数选中心。它是信息选择规则，不是新的目标胜率。
- 两策略按各自指定指标排序；四策略优先按非零通关差异排序，无通关信号时才以清除关数回退，不跨量纲比较绝对值。随后按ID；不足名额不事后换成更有利的一类。每个问题的具体配置、主指标、差异方向与难度在开启P2新种子之前登记。

P2采用新世界种子，不训练或重调策略。报告1000世界、最多2000轨迹/格；不保证所有10个百分点或更小差异都有足够检出能力。未确定仍写未确定，不因“不显著”继续补到显著。

## 6. 随机流与可复现性

- 世界种子：`matrix-v1:<split>:world:<index>`，不含策略ID；同一分区内，各策略与难度使用相同世界索引。
- 行为种子：`matrix-v1:<split>:world:<index>:behavior:<rep>`。保存每次随机选择、实际概率和流位置。
- 反事实估计使用独立的公开状态派生流，不读取真实未来。
- 状态库、P0、P1、P2、过程分叉筛查、分叉确认、后续调优验证使用不同命名空间；不根据种子结果筛掉差局。
- 同一初始世界不保证不同操作后的棋盘、候选与条款相同。重掷、招募与移除会改变随机调用；配对的是初始世界或入口，不是完全相同的未来。
- 分叉保存完整游戏状态、策略参数/偏好记忆、行为RNG位置。正常分支必须先逐动作复现原续局，不能从头重启行为RNG。

## 7. 逐关、逐转、逐动作必须记录什么

每关有3个明确定义的边界：A入关效果与补充资源完成、首个玩家动作之前；B清场/失败即时、清场奖金与被动之前；C本关奖励处理完成、进入下一关之前。下一关的免费资源计在下一关A。当前引擎会在动作内连续处理这些事件，需用只读边界观测；不能拿一个动作后状态冒充三者。

| 类别 | 指标与分母 |
| --- | --- |
| 生存 | 到达f关/全部开局；清除f关/全部开局；f关失败/进入f关，按生命、期限分因；每局清除关数0–12 |
| 清场压力 | 实际使用转数、实际期限、剩余转数及剩余/期限；仅剩最后一次才清场的比例；清关者P10/P50/P90及人数，失败者独立列出 |
| 防御代价 | A→B净生命/盾变化；敌方实际失血、自损、污染、实际治疗、获得盾、实际抵盾、盾衰减分别记账；最大生命改变另列 |
| 资源 | 信用点收入/消费/余额；免费和付费重掷、移除、三种补给次数/费用、购买额度使用；合法机会、模型预判值得的机会、使用和放弃机会 |
| 构筑 | 候选曝光、招募/跳过、升星、队伍规模、稀释、实际登场、技能触发；永久属性发放与当前留存分别记录 |
| 投资兑现 | 选择时预计N/F、预计时间，实际后续触发、成长留存、经济/精华兑现与未到兑现就失败；这是估计校验，不能把模型分数当真实收益 |
| 奖励节奏 | 每关转数、招募次数、奖金、奇物与精华的获得时点，区分战斗内与清关后 |
| 决策随机性 | 原始评分分量、完整动作概率、选择熵、最高评分项选择率、放弃最高项的分差、真实行为随机数 |
| 完整性 | 终局/未完成、动作上限、无进展、非法状态、异常、墙钟/CPU耗时、唯一试验键、源码/策略身份 |

逐转伤害只统计实际扣血，不能因敌人剩余生命截断就说早清者战力较弱。净生命变化不等于实际承伤；resourceStats.hpLost还包含自损和污染。补给会改写lastSpin的治疗/盾累计，逐关汇总使用资源账本差分和事件账本，不能直接加lastSpin字段。

守恒检查需覆盖HP、护盾、信用点、重掷和移除余额。HP账单显式列治疗、敌伤、自损/污染及生命上限变化造成的调整；盾单独列抵伤、衰减和其他损失；现金列所有收入与支出。按引擎两位小数舍入设容差，无法对账的批次拒绝进入正式分析。

提前失败者在后续生存曲线中保持失败；后期伤害、盾和余量不虚填0来混进幸存者均值，而是同时显示未到达数、条件分布与全局生存。未完成任务不算输，也不静默删掉；主报告披露计划数/尝试数/终局数/异常数，结构性异常须修复并按新源码身份重测相关批次。

## 8. “忽略资源后一两关怎样”的分叉实验

这是独立于自然矩阵的过程证据。自然对局里“少花钱者输了”只能说明相关性。

首个受影响关固定为 **2、4、6、8、10**，观察它及后两关。机会在上关清场奖励阶段出现时，按下一次实际战斗所属关计时，不能把已经清掉的上关算作一次响应。

具体机制分为3类：重掷、移除、补给；补给再分医疗/护盾/超频描述，重掷分免费/付费描述。信用点与防御有重叠，不把这些效应当互不相干并相加。

资格在分叉前确定：记录全部合法机会作为曝光分母；分叉入口要求资源可用且正常根策略本来会执行该类资源动作，保证A与错失分支确实发生动作差异。冻结的公开信息审计器另标记“预计有价值”及分数，不根据后来谁输谁赢倒选。分叉结果分别报告全部合格入口及审计器认为有价值的子集；它们不代表所有合法动作都有价值。根策略不打算执行的合法动作只报曝光/忽略情况，不冒充已经获得分叉因果结果。无资源、无合格机会者记未暴露，不当作零效应。

每个入口复制5个分支，其他行为保持相应根策略：

| 分支 | 干预 |
| --- | --- |
| A 正常 | 正常规划，作为控制 |
| B 一次错失 | 放弃该机会，随后恢复；重掷机会以本次奖励选定为窗口，移除（含奖励阶段出现的移除）/补给以接下来的真实转动为窗口，防止下一条指令立刻补做而成为空干预 |
| C 本关忽略 | 首个受影响关结束前停止这类经营，下一关恢复 |
| D 持续忽略 | 从此不再做这类经营，其余规则照常 |
| E 主动补救 | 同B错失一次；恢复后本关余下及后两关使用积极投入R=0.5，再恢复原R，衡量补救策略的总效果与成本 |

自然治疗/护盾全部保留，不消除角色技能，不给任何分支额外资源。B/C/D是真实机会错失，E不是凭空返还资源。不能把E的效果说成“纯粹恢复一次动作”的效应。

筛查面板：`D4/D8/D12/D16/D20 × 5检查关 × 3动作类 × 128独立入口 × 5分支 × 2行为复本 = 96,000条续局上限`。

- 根策略固定无队伍偏好、ε=0.15、R=1，H取三档。根轨迹每H×D最多检索512世界，最多7,680完整局；同一格同一世界只取一个入口，三种H均衡抽取，无法均衡则披露。
- 候选按预先种子顺序收集，不看后续结果；记录合法机会率和有价值机会率。高难晚期凑不齐时保留缺样，不人工增强队伍，也不宣称已覆盖。
- 最多选8个问题格做独立确认：重掷/移除/补给各至少2个有资格问题格，其余2个按风险差绝对值选择，优先覆盖不同检查阶段。无资格者不凑数。
- 确认每格目标1,000个新世界入口、两行为复本、五分支，最多80,000条续局；每格最多检索4,096个候选世界，最多32,768完整根局。根H按冻结种子分配，入口不足照实披露。

主要过程终点：清除受影响关、下一关、下两关之前的累计失败风险差；同时报告仍存活者的清场余量、防御储备与额外应急费用。末关截止、提前失败、没有暴露、没有到达，不能互相替代。32个非控制分支对照各有3个响应时点，最多96项正式过程比较。

## 9. 早清、拖延与成长的诊断

比较真实合法路线，例如当前超频/即时卡争取早清与保留预算/成长投资。记录每条路线的转数、额外招募、永久成长、精华进度、承伤、后续资源和生存。游戏没有等待动作，不通过锁敌人生命、免费延长回合或修改角色伤害来制造拖延。

先从主矩阵的H×R、阶段变化与实际奖励次数找线索，再把相关入口纳入已登记的过程问题。路线结果是整套选择的总效应，不能把额外招募、随机变化、补给支出都归为纯“多一次转动”的效果。

自然对局中的角色曝光、选择、升星与贡献只作描述：高胜率队伍常拿某角色不证明该卡过强。需归因单卡时另立受控替换/技能干预，不混入本次自然矩阵的因果结论。

## 10. 分析方法与判读

### 10.1 先逐格，再看因素与交互

每格给实际世界数、轨迹数、胜负/未完成、12关生存曲线和逐关指标分布。所有主图按难度显示，不只报告跨D平均胜率。跨策略等权平均代表本实验策略分布，不代表真实玩家人口分布。

探索模型使用分类因素T/H/J/R，难度作为分类或平滑项，检查H×D、J×D、R×D、H×R、T×H、T×J，以及必要的三因素线索。模型收缩可辅助找结构，不能替代原始分格数据；低样本格不输出过度精确排名，D1全胜/D20全败也保留并改看余量与到达关卡。

P2二策略比较在同一世界内求差；交互用四策略差异之差。例：贪婪相对短期在积极资源与囤积资源下的收益差，再求一次差；不能仅凭一组显著另一组不显著就认定存在交互。

### 10.2 区间与多重比较

- 先对同世界的行为复本平均，再按世界种子整块重抽样，保留策略、难度、12关与分支的相关结构。描述性近似95%区间使用10,000次固定分析种子的块bootstrap；中心化种子块重抽样初始100,000次，p值使用加一修正，作为诊断保留。MC误差可能改变正式Holm结论时，按预定规则统一提高至1,000,000次，并取MC区间保守上界；仍不稳定则写未确定。这里只增加统计计算，不补游戏样本，也不选较小的一次p值。
- 2026-10-26独立离线统计资格验证发现，中心化bootstrap在偏斜、有界零均值情形会失准。例如1,000世界的合法清除关数差取−0.5或+12，P(+12)=0.04，真实均值为0；在α=0.025/72时，其精确实际错误率约0.001179，高于目标约0.000347。因此它不能单独作为正式确认p值，不能靠Holm修复。
- 正式方法增加有理论保证的有界护栏：每世界策略差或四臂交互差D落在预登记范围[a,b]，使用 `p_H=min(1,2×exp(−2N×mean(D)^2/(b−a)^2))`，正式p取 `max(p_H, bootstrap的MC保守上界)`。配对胜率差范围为[−1,1]，四策略交互为[−2,2]；清除关数差分别为[−12,12]、[−24,24]。必须核验每个值在理论范围内，不按观察到的数据缩小范围。独立世界及正确范围条件下，正式p至少与Hoeffding有界检验一样保守，随后再做Holm。
- 0胜/全胜、全零差或方差退化时，不能用零宽bootstrap区间或虚假的极小p。胜率另列预先指定每世界第一个行为复本的Wilson/精确二项区间；确认效应另给Hoeffding保守95%区间，退化数据也用有界p。不得把2N轨迹当独立样本。详细资格报告记录原方法失败、新护栏资格、对称/偏斜/稀疏/四臂已知零均值统计数据及源码哈希；这不运行游戏。
- 正式主矩阵最多72项，Holm控制该family α=0.025；过程最多96项，另以Holm控制α=0.025。两family总体错误率目标不超过0.05，前提为独立世界与预登记有界范围；未完成的预定比较不换成更有利的问题。保守护栏明显降低检出力：N=1,000且按72项最严阈值时，观测到的配对胜率差需约13.2个百分点、清除关数差约1.58关，四臂交互约26.3个百分点/3.16关，才可能越过这一最严门槛。固定样本不保证原优先级幅度的差异能获正式确认，不为显著性追加游戏样本。
- 其他大量探索只展示效应/区间与明确探索标识；如需要显著性筛选，使用考虑依赖的BY-FDR，q=0.10，不冒充确认。
- 95%描述区间不是同时覆盖所有格子的保证。正式结论同时看调整后的检验、实际差异与估计不确定性，不只看p值。

单个固定行为复本的二项区间精度参考：N=16在50%附近约±22个百分点；N=128约±8.5个百分点；N=1,000约±3.1个百分点。它们不是“两个复本后精度翻倍”，也不是多重比较后的检出能力保证。

用于优先检查的建议实际差异：通关/两关失败风险10个百分点、每局清除关数1关、清场余量1次；四策略交互关注20个百分点量级。它们只是本次问题优先级，不是平衡及格线；所有更小差异仍保留。若区间宽到无法排除实质差异，写证据不足，不写相近或已平衡。

### 10.3 随机性较强策略更好时怎样查

先核对动作集合、跳过、预算、资源风格、实现与种子独立性，再比较同T/H/R下J的总效应。对无偏好、均衡H的情况另看ε=1控制。接着检查：低随机是否过度信任错误分数、过度专注标签、错估合成/精华、忽略当前危险或未认识组合。

在独立确认中复现后，分别给“估值/实现问题”和“规则导致的激励问题”的证据。不能直接写随机胜出已经证明设计坏了，也不能通过移除随机策略的合法动作来消除差异。

## 11. 数据交付、成本和中止规则

每条记录含唯一试验键、策略完整配置、世界/行为流位置、难度、逐关事件和完整终局。保存分片起止索引、计划/实际计数、header/footer、源码哈希、策略哈希、SHA-256与父子分叉关系。

初始每片500完整局或1,000续局，流式gzip JSONL写出，断点续跑不换种子、不重复计数；汇总独立流式读取，不把百万局装入内存。常规全量保存逐动作/逐关账本；全卡逐击中账本保留固定5%哈希样本和登记的问题入口，不能只保存赢家。其余轨迹可由完整状态、动作和流精确重演。

P0按8/4/1 worker的少量重复计时检查吞吐与调度一致性，默认最高8 worker并留出交互余量；时间预算用实测吞吐估计，报告压缩存储与可用磁盘。大原始数据保存在本地或已授权私有制品位置，Git只保存协议、清单、统计、索引与小样本，不自动上传大批轨迹到新服务。

单局先限1,000动作；P0发现合法局需要更多时，在正式冻结前统一修改上限。非法动作、账不平、状态变化、源码漂移、重复键或正常分支无法重演时，停止受影响批次修复；不能把这些当玩家失败。固定样本量跑完才做正式判断，不边看显著性边停。实际预算不足则报告已覆盖与缺口，不默默缩水后宣布完成。

最终交付包含：策略字典、可复现命令与运行配置、原始分片清单、难度×策略概览、逐关压力图、投资兑现图、随机性诊断、分叉与补救曲线、异常/缺样表，以及“规则问题/AI问题/证据不足/需要人工试玩”的问题清单。调数值属于下一阶段，需依据这些结果另提候选和验证方案。

## 方法参考

Wilson及稀疏样本的精确二项边界用于解释比例的不确定性，参见 [NIST：比例置信区间](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)。这不意味着可把相关复本直接当独立二项样本。

Holm可控制家族错误率，BY可在一般依赖结构下控制FDR；两者用途不同，参见 [R stats：p.adjust 官方说明](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/p.adjust.html)。本协议具体策略、样本预算、两组错误预算与实践差异均为本项目提出的实验选择。正式护栏参考 [Hoeffding 1963 原论文](https://www.tandfonline.com/doi/abs/10.1080/01621459.1963.10500830) 的独立有界和偏差概率界。
